# Challenges

강의에서 파생한 `practice/`와 분리해, 외부 문제 플랫폼에서 직접 푼
제출 코드를 보관합니다. 문제 통과 수를 기록하는 곳이 아니라, 짧은
구현과 그 구현에서 확인한 계약·결과·의문을 다시 찾기 위한 공간입니다.

- `deep-ml/`: Deep-ML에서 만든 머신러닝 문제 풀이

강의 학습 성과를 구현·검사·해석하는 Notebook은 계속 `practice/`에 둡니다.

외부 challenge나 competition은 현재 승인 활동에 필요한 짧은 알고리즘·API
구현 또는 데이터·평가 경험이 실제로 있을 때만 제안합니다. 항목의 현재
존재·규칙·접근 조건을 먼저 확인하고, 정확한 provider·offering·problem을
기록합니다. 계정 접근, 참여, 제출은 사용자 승인 전에는 수행하지 않습니다.

통과 표시는 플랫폼 채점 결과입니다. 실제 수행·도움·실행/해석·미확인을 구별하고,
통과만으로 이해·독립 숙달·지연 기억을 확정하지 않습니다. 현재 북마크는
[STATE](../STATE.md), 근거 판단은 [공통 정책](../.agents/references/learning-policies.md#evidence-and-long-term-review)을 따릅니다.
