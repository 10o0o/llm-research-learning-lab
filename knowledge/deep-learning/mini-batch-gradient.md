# 미니배치 기울기와 SGD

## 핵심 요약

SGD는 무작위로 고른 데이터의 손실 기울기로 가중치를 갱신한다. 미니배치 크기를 늘리면 한 번에 처리할 데이터가 늘고, 같은 가중치에서 추정하는 평균 기울기의 흔들림은 일반적으로 줄어든다. 한 번 갱신할 때 전체 손실이 반드시 감소하는 것은 아니다.

## 개념 정리

현재 가중치에서 선택한 데이터의 손실 기울기를 계산하고, 양의 학습률을 곱해 가중치에서 뺀다. 가중치와 기울기는 같은 크기로 대응한다. 전체 데이터 대신 일부를 사용하면 갱신에 필요한 계산을 줄일 수 있다.

평균 손실의 기울기를 비교할 때는 데이터별 기울기의 평균을 사용한다. 합 손실과 평균 손실은 배율이 다르므로 학습률을 비교할 때 이 차이를 함께 확인한다. 가중치를 고정한 상태의 표본 평균 성질과, 가중치를 매번 바꾸는 학습의 수렴은 구별한다.

## 주의점

정상적인 데이터도 개별 기울기가 전체 평균과 다를 수 있다. 손실 증가를 곧바로 데이터 품질이나 이상치 탓으로 판단하지 않는다. 반복 횟수가 많다는 이유만으로 학습 개선이 보장되지 않으며 학습률과 목적함수 등의 조건이 필요하다.
