# 계산 그래프와 역전파

## 핵심 요약

자동미분은 순전파에서 계산 연결을 기록하고, 최종 출력에서 역방향으로 국소 기울기를 곱해 전달한다. 같은 입력에 여러 경로의 기여가 도착하면 더한다. 기울기 계산과 파라미터 업데이트는 별개다.

## 개념 정리

### 스칼라 Value에 저장하는 것

| 속성 | 역할 |
|---|---|
| `data` | 순전파로 계산한 숫자 하나 |
| `grad` | 선택한 최종 출력에 대한 이 값의 기울기 |
| `_prev` | 결과를 만드는 데 직접 사용한 입력 객체 집합 |
| `_op` | 연산 종류 |
| `label` | 사람이 읽는 이름 |
| `_backward` | 직접 입력에 기울기를 전달할 함수 |

숫자 하나만 저장하면 어떻게 만들어졌는지 알 수 없다. 입력 객체의 참조를 함께 저장하면 DFS로 이전 계산을 찾을 수 있다. 그래프의 사각형은 `Value`이고, 연산 기호는 `_op`를 별도 표시한 것이다. 객체를 구별하는 `id`와 화면에 표시하는 이름은 역할이 다르다.

### 국소 기울기와 최종 출력에 대한 기울기

$$
d=e+c,\qquad L=df
$$

$$
\frac{\partial L}{\partial c}
=\frac{\partial L}{\partial d}\frac{\partial d}{\partial c}
=f\times1
$$

`f.data`가 −2이면 덧셈의 국소 기울기는 1이지만 `c.grad`는 −2다. `.grad`를 읽을 때는 어느 출력을 기준으로 역전파했는지 알아야 한다.

| 연산 | 입력에 누적할 기여 |
|---|---|
| 덧셈 | 입력마다 `out.grad` |
| 곱셈 | 반대편 입력의 `.data * out.grad` |
| 고정 지수의 거듭제곱 | `p * self.data**(p - 1) * out.grad` |
| 지수함수 | `out.data * out.grad` |
| 자연로그 | `out.grad / self.data` |
| tanh | `(1 - out.data**2) * out.grad` |

### 시작 기울기와 실행 순서

최종 출력을 기준으로 역전파를 시작할 때 자기 자신에 대한 기울기를 1로 둔다.

$$
\frac{\partial L}{\partial L}=1
$$

이는 출력값이 1이라는 뜻이 아니다. 예를 들어 뉴런 출력값은 약 0.7071이어도 출력의 시작 기울기는 1이다.

`backward()`는 입력을 먼저 DFS로 방문한 뒤 현재 노드를 리스트에 추가한다. 이 위상 순서를 뒤집으면 결과 쪽 연산들이 입력 쪽 연산들보다 먼저 실행된다.

```text
순전파: e = a * b, d = e + c
가능한 위상 순서: a, b, e, c, d
역전파 순서: d, c, e, b, a
```

서로 독립적인 노드의 순서는 달라도 된다. `e`가 자기 입력에 전달하기 전에 `d`의 기울기를 받아야 한다는 의존관계가 중요하다. `visited`는 각 객체를 한 번만 순서에 넣는다.

### 함수 저장과 호출

```python
out._backward = _backward
```

위 코드는 함수를 저장한다. 괄호를 붙이면 순전파 중 즉시 실행하고 반환값 `None`을 저장하게 된다. 실제 호출은 기울기가 준비된 뒤 `out._backward()`로 한다.

안쪽 함수는 입력·출력 객체를 참조하는 클로저다. 호출 시점의 `out.grad`를 읽는다. `_backward()`는 연산 하나를 처리하고, `backward()`는 전체 그래프의 순서를 구성해 각 함수를 호출한다.

### 경로별 기울기 누적

$$
y=x+x\quad\Rightarrow\quad\frac{dy}{dx}=1+1=2
$$

두 피연산자가 같은 객체이므로, 덧셈 함수 안의 두 누적문이 같은 `.grad`에 각각 1을 더한다. `_prev`에서 객체가 한 번만 나타나도 연산별 기여는 둘 다 필요하다.

$$
u=x^2,\qquad y=u+x,\qquad
\left.\frac{dy}{dx}\right|_{x=3}=6+1=7
$$

제곱 경로의 기여 6과 직접 덧셈 경로의 기여 1이 합쳐진다. `u.grad` 자체는 1이며, 제곱의 국소 기울기 6을 곱해야 해당 경로의 입력 기여가 된다.

### 연산을 재사용하는 Python 메서드

| 표현 | 처리 |
|---|---|
| `value + number` | 숫자를 `Value`로 감싼 뒤 덧셈 |
| `number + value` | `__radd__`에서 기존 덧셈 재사용; `sum`의 시작값 0 처리 |
| `-value` | −1과 곱셈 |
| `value**-1` | 역수이며 부호 반전과 다름 |
| `a / b` | 역수와 곱셈으로 그래프 구성 |

새 연산을 조합할 때는 객체 연산을 반환해야 연결이 유지된다. 이 스칼라 엔진의 `_backward` 안에서는 `.data`로 숫자 기울기를 계산해 숫자 `.grad`에 누적한다.

## 예제 또는 적용

같은 스칼라 함수는 하나의 연산으로 만들거나 작은 연산들로 분해할 수 있다.

$$
\tanh(n)=\frac{\exp(2n)-1}{\exp(2n)+1}
$$

입력 약 0.88137에서 직접 `tanh`와 분해 그래프의 출력은 약 0.7071, 입력 기울기는 약 0.5로 일치한다. 지수함수 결과가 분자·분모 두 경로에 사용되므로 기여를 누적해야 한다. 두 구현을 비교할 때는 같은 값의 별도 입력 객체를 사용해 서로의 기울기가 섞이지 않게 한다.

PyTorch의 뉴런 비교에서는 원소 하나인 Tensor `(1,)`를 사용했다. `requires_grad=True`로 연산을 추적하고 `backward()` 후 입력 Tensor의 `.grad`를 읽는다. 기울기를 구하는 것만으로 Tensor 값이 업데이트되지는 않는다.

## 주의점

- `data`를 바꿔도 기존 중간 객체의 계산값은 자동으로 갱신되지 않는다. 새 출력은 순전파를 다시 수행해 구한다.
- 이 `backward()`는 기존 기울기를 자동 초기화하지 않는다. 새 순전파 그래프와 파라미터 grad 초기화를 구분한다.
- 클래스 정의 셀을 수정해도 기존 객체가 새 클래스의 객체가 되지 않는다. 정의 셀 실행 후 입력·결과 객체를 다시 만든다.
- `o = n.tanh()`는 새 출력 객체를 만든다. 반면 같은 객체에 이미 설정한 시작 기울기를 불필요하게 다시 설정할 필요는 없다.
- 저장된 출력과 현재 코드는 다를 수 있다. 수정한 정의 → 객체 생성 → 실행 순서로 확인한다.
- 이 구현은 스칼라 자동미분 학습용이다. Tensor 연산·고차 미분·큰 입력에서의 수치 안정성까지 구현했다고 간주하지 않는다.
