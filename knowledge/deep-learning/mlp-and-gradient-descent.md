# MLP 구성과 경사하강 학습

## 핵심 요약

뉴런은 입력별 가중합에 편향을 더하고 활성화 함수를 적용한다. 여러 뉴런을 층으로 묶고 층의 출력을 다음 층에 전달하면 MLP가 된다. 학습에서는 loss에 대한 파라미터 기울기를 구하고, 그 반대 방향으로 가중치와 편향을 조정한다.

## 개념 정리

### 뉴런의 입력과 파라미터

$$
n=\sum_i w_i x_i+b,\qquad o=\tanh(n)
$$

입력은 데이터이고, 가중치와 편향은 조절할 파라미터다. micrograd에서는 각 값이 스칼라 `Value`이며, 입력 여러 개를 Python 리스트로 전달한다.

- 입력 세 개를 받는 뉴런: 가중치 3개와 편향 1개, 총 4개 파라미터.
- `__init__`: 파라미터를 생성한다.
- `__call__`: 저장된 파라미터와 주어진 입력으로 새 계산 그래프를 만든다.
- `parameters()`: 입력 데이터가 아니라 학습 대상인 가중치와 편향 객체를 모은다.

입력이 0인 자리에서는 해당 가중치를 바꿔도 곱이 0이므로 그 데이터에 대한 가중치 기울기는 0이다. 같은 자리의 입력 기울기는 가중치에 따라 0이 아닐 수 있다. 무엇을 바꾸고 무엇을 고정하는지가 다르다.

### 층과 MLP의 크기

`Layer(nin, nout)`은 같은 입력을 받는 별도 뉴런 `nout`개를 만든다. 각 뉴런은 자기 가중치와 편향을 가진다.

$$
\text{층의 파라미터 수}=(n_{\mathrm{in}}+1)n_{\mathrm{out}}
$$

`MLP(3, [4, 4, 1])`의 연결은 다음과 같다.

| 층 | 입력 수 | 출력 수 | 파라미터 수 |
|---|---:|---:|---:|
| 첫 번째 | 3 | 4 | 16 |
| 두 번째 | 4 | 4 | 20 |
| 마지막 | 4 | 1 | 5 |
| 합계 | | | 41 |

```text
숫자 3개 리스트 → Value 4개 리스트 → Value 4개 리스트 → Value 하나
```

첫 층이 출력값 네 개를 만들기 때문에 다음 층의 각 뉴런이 입력 네 개를 받는다. 출력 숫자 자체가 4라는 뜻이 아니다. 층 사이에 `.data`만 넘기지 않고 객체를 전달해 그래프 연결을 유지한다.

이 학습용 `Layer`는 뉴런이 하나일 때 리스트가 아닌 `Value` 하나를 반환한다. 모든 층에서 `tanh`를 사용하며, 현재 예제의 단일 출력 층은 마지막에 둔다.

### 제곱 오차 합으로 목표 정하기

$$
L=\sum_i(\hat y_i-y_i)^2
$$

오차를 제곱하면 반대 부호끼리 상쇄되지 않는다. 목표 −1에 대해 +0.8을 예측하면 해당 항은 3.24이며, 예측이 감소하는 방향이 바람직하다. 여기서는 평균이 아닌 네 데이터의 제곱 오차 합을 사용했다.

```text
입력 네 건, 각 숫자 세 개
→ 같은 model로 예측 Value 네 개
→ 제곱 오차 Value 네 개
→ 합계 loss Value 하나
```

네 예측은 같은 파라미터 객체를 사용하므로 loss 역전파에서 데이터별 기여가 합쳐진다.

### 계산, 초기화, 업데이트의 분리

```text
현재 파라미터로 새 순전파 그래프와 loss 생성
→ 파라미터 grad를 0으로 초기화
→ loss.backward()
→ 파라미터 업데이트
→ 바뀐 파라미터로 새 예측과 loss 확인
```

새 순전파로 만들어진 중간 노드의 grad는 0이지만, 재사용하는 파라미터 객체에는 이전 grad가 남을 수 있다. 그래서 파라미터 grad를 별도로 초기화한다.

$$
\theta_{\mathrm{new}}=\theta-\eta\frac{\partial L}{\partial\theta}
$$

양의 학습률을 사용해 기울기를 빼면 경사하강이다. 기울기를 더하는 경사상승은 출력을 키울 때의 방향이다. `backward()`는 기울기만 계산하며 업데이트는 별도 실행한다.

기존 `loss.data`는 이전 순전파의 값이다. 업데이트 이후 loss는 바뀐 파라미터로 다시 계산해야 한다. 반복 안에서 업데이트 후 이전 loss를 출력해도 그것은 업데이트 직전 값이다.

## 예제 또는 적용

연결된 micrograd 실습에서 제곱 오차 합은 초기 약 5.23052에서 한 번 업데이트 후 3.12411로 감소했다. 이후 20회 추가 학습 후 약 0.03218이 되었고, 목표 `[1, -1, -1, 1]`에 대한 예측은 약 `[0.90893, -0.95325, -0.87975, 0.91494]`였다.

이 예제는 네 데이터에서의 학습 과정을 보여준다. 새로운 데이터에서의 일반화 성능은 이 결과로 판단하지 않는다.

## 주의점

- 학습률이 고정되어 있다고 매 단계 loss 감소가 보장되지는 않는다. 실습에서도 중간에 한 번 증가했다.
- 전체 오차를 줄이는 업데이트가 모든 데이터의 개별 오차를 동시에 줄일 필요는 없다.
- 리스트 컴프리헨션은 바깥 반복문부터 쓴다. `for neuron in self.neurons` 다음에 `for p in neuron.parameters()`가 와야 현재 층의 파라미터를 모은다.
- 이전 전역 변수 때문에 틀린 반복문도 개수만 맞을 수 있다. 파라미터 수와 함께 어떤 객체를 수집하는지 확인한다.
- 기존 모델을 이어서 학습하는 것과 모델을 새로 초기화하는 것을 구분한다.
