# MLP 구성과 경사하강 학습

## 핵심 요약

뉴런은 입력별 가중합에 편향을 더하고 활성화 함수를 적용한다. 여러 뉴런을 층으로 묶고 층의 출력을 다음 층에 전달하면 MLP가 된다. 학습에서는 loss에 대한 파라미터 기울기를 구하고, 그 반대 방향으로 가중치와 편향을 조정한다.

## 개념 정리

### 뉴런의 입력과 파라미터

$$
n=\sum_i w_i x_i+b,\qquad o=\tanh(n)
$$

입력은 데이터이고, 가중치와 편향은 조절할 파라미터다. micrograd에서는 각 값이 스칼라 `Value`이며, 입력 여러 개를 Python 리스트로 전달한다.

- 입력 세 개를 받는 뉴런: 가중치 3개와 편향 1개, 총 4개 파라미터.
- `__init__`: 파라미터를 생성한다.
- `__call__`: 저장된 파라미터와 주어진 입력으로 새 계산 그래프를 만든다.
- `parameters()`: 입력 데이터가 아니라 학습 대상인 가중치와 편향 객체를 모은다.

입력이 0인 자리에서는 해당 가중치를 바꿔도 곱이 0이므로 그 데이터에 대한 가중치 기울기는 0이다. 같은 자리의 입력 기울기는 가중치에 따라 0이 아닐 수 있다. 무엇을 바꾸고 무엇을 고정하는지가 다르다.

### 층과 MLP의 크기

`Layer(nin, nout)`은 같은 입력을 받는 별도 뉴런 `nout`개를 만든다. 각 뉴런은 자기 가중치와 편향을 가진다.

$$
\text{층의 파라미터 수}=(n_{\mathrm{in}}+1)n_{\mathrm{out}}
$$

`MLP(3, [4, 4, 1])`의 연결은 다음과 같다.

| 층 | 입력 수 | 출력 수 | 파라미터 수 |
|---|---:|---:|---:|
| 첫 번째 | 3 | 4 | 16 |
| 두 번째 | 4 | 4 | 20 |
| 마지막 | 4 | 1 | 5 |
| 합계 | | | 41 |

```text
숫자 3개 리스트 → Value 4개 리스트 → Value 4개 리스트 → Value 하나
```

첫 층이 출력값 네 개를 만들기 때문에 다음 층의 각 뉴런이 입력 네 개를 받는다. 출력 숫자 자체가 4라는 뜻이 아니다. 층 사이에 `.data`만 넘기지 않고 객체를 전달해 그래프 연결을 유지한다.

이 학습용 `Layer`는 뉴런이 하나일 때 리스트가 아닌 `Value` 하나를 반환한다. 모든 층에서 `tanh`를 사용하며, 현재 예제의 단일 출력 층은 마지막에 둔다.

### 제곱 오차 합으로 목표 정하기

$$
L=\sum_i(\hat y_i-y_i)^2
$$

오차를 제곱하면 반대 부호끼리 상쇄되지 않는다. 목표 −1에 대해 +0.8을 예측하면 해당 항은 3.24이며, 예측이 감소하는 방향이 바람직하다. 여기서는 평균이 아닌 네 데이터의 제곱 오차 합을 사용했다.

```text
입력 네 건, 각 숫자 세 개
→ 같은 model로 예측 Value 네 개
→ 제곱 오차 Value 네 개
→ 합계 loss Value 하나
```

네 예측은 같은 파라미터 객체를 사용하므로 loss 역전파에서 데이터별 기여가 합쳐진다.

### 계산, 초기화, 업데이트의 분리

```text
현재 파라미터로 새 순전파 그래프와 loss 생성
→ 파라미터 grad를 0으로 초기화
→ loss.backward()
→ 파라미터 업데이트
→ 바뀐 파라미터로 새 예측과 loss 확인
```

새 순전파로 만들어진 중간 노드의 grad는 0이지만, 재사용하는 파라미터 객체에는 이전 grad가 남을 수 있다. 그래서 파라미터 grad를 별도로 초기화한다.

$$
\theta_{\mathrm{new}}=\theta-\eta\frac{\partial L}{\partial\theta}
$$

양의 학습률을 사용해 기울기를 빼면 경사하강이다. 같은 손실의 기울기를 더하는 경사상승은 그 손실을 국소적으로 키우는 방향이다. `backward()`는 기울기만 계산하며 업데이트는 별도 실행한다.

기존 `loss.data`는 이전 순전파의 값이다. 업데이트 이후 loss는 바뀐 파라미터로 다시 계산해야 한다. 반복 안에서 업데이트 후 이전 loss를 출력해도 그것은 업데이트 직전 값이다.

### 학습률의 역할

학습률은 gradient에 곱하는 갱신 크기를 정한다. 너무 작으면 파라미터가
조금씩 변해 학습에 많은 반복이 필요할 수 있다. 너무 크면 낮은 손실 영역을
지나치거나 갱신이 불안정해 손실이 증가할 수 있다. 작은 학습률이 언제나
더 좋은 것은 아니며, 학습 횟수와 초기 상태를 함께 확인해야 한다.

## 예제 또는 적용

### 초기화와 데이터에 의한 학습

출력층의 무작위 가중치를 작게 하고 편향을 0으로 두면, 고정된 은닉층
출력에 대한 logits의 크기와 차이를 줄일 수 있다. 초기 예측을 균등 확률에
가깝게 만들어 근거 없는 강한 확신을 완화하는 방법이다. 정답의 gradient로
파라미터를 조정하는 학습과는 다르며, 분산 감소가 항상 손실 감소를 보장하지 않는다.

27개 문자에 동일한 확률을 주면 어떤 정답 문자에 대해서도 손실은 같다.

$$
-\log(1/27)=\log(27)\approx 3.2958
$$

이는 시작점의 기준이다. 이후 학습은 정답으로 계산한 손실의 gradient를
이용해 파라미터를 바꾼다. 같은 배치의 손실 감소만으로 새 데이터에 대한
성능 향상을 판단할 수는 없다.

입력 네 건과 목표 `[1, -1, -1, 1]`을 사용한 micrograd 예제에서 제곱 오차 합은 초기 약 5.23052, 한 번 업데이트한 뒤 3.12411, 이후 20회 추가 학습한 뒤 약 0.03218이었다. 마지막 예측은 약 `[0.90893, -0.95325, -0.87975, 0.91494]`였다.

이 예제는 네 데이터에서의 학습 과정을 보여준다. 새로운 데이터에서의 일반화 성능은 이 결과로 판단하지 않는다.

### 문자 MLP의 임베딩과 직접 연결

실습의 문맥 3문자, 임베딩 차원 10, 은닉 유닛 200, 출력 문자 27개 모델은
문자 ID로 임베딩 테이블의 행을 조회하고, 문맥별 벡터를 이어 붙인다.
`C[X]`는 ID를 이용한 행 선택이며 ID 자체와 가중치를 행렬곱하는 것이 아니다.

| 단계 | 입력 또는 가중치 | 결과 shape |
|---|---|---|
| 임베딩 조회 | ID `(B, 3)`, 테이블 `(27, 10)` | `(B, 3, 10)` |
| 문맥 벡터 연결 | 임베딩 | `(B, 30)` |
| 은닉층과 tanh | 가중치 `(30, 200)`, 편향 `(200,)` | `(B, 200)` |
| 출력층 | 가중치 `(200, 27)`, 편향 `(27,)` | `(B, 27)` |
| 추가 직접 경로 | 연결된 임베딩, 가중치 `(30, 27)` | `(B, 27)` |

직접 경로의 점수를 기존 은닉층 경로의 logits에 더한다. 두 결과 모두
`(B, 27)`이어야 한다. 직접 가중치를 0으로 시작하면 처음에는 추가 점수가
0이므로 기존 모델과 출력이 같다. 이후 두 경로를 함께 학습하며 직접
가중치도 학습 대상 목록에 포함한다. 추가 파라미터는 810개다.

예를 들어 입력 두 건이면 두 경로 모두 문자별 점수 `(2, 27)`을 만든다.
이 점수의 합을 cross-entropy에 전달하며, 확률이 필요할 때 softmax를 쓴다.
한 번의 작은 dev loss 개선이 모든 실행에서의 우위를 보장하지는 않는다.

## 주의점

- 학습률이 고정되어 있다고 매 단계 loss 감소가 보장되지는 않는다. 이 예제에서도 중간에 한 번 증가했다.
- 전체 오차를 줄이는 업데이트가 모든 데이터의 개별 오차를 동시에 줄일 필요는 없다.
- 리스트 컴프리헨션은 바깥 반복문부터 쓴다. `for neuron in self.neurons` 다음에 `for p in neuron.parameters()`가 와야 현재 층의 파라미터를 모은다.
- 이전 전역 변수 때문에 틀린 반복문도 개수만 맞을 수 있다. 파라미터 수와 함께 어떤 객체를 수집하는지 확인한다.
- 기존 모델을 이어서 학습하는 것과 모델을 새로 초기화하는 것을 구분한다.
