# 모델 비교 실험과 결과 해석

## 핵심 요약

설정 하나의 효과를 비교하려면 나머지 조건을 맞춘다. train과 dev에서
관찰한 개선을 기록하되, 여러 설정을 동시에 바꾼 결과나 한 번의 실행만으로
개선 원인과 일관된 우위를 확정하지 않는다.

## 개념 정리

### 비교 조건과 원인 분리

학습률을 비교할 때는 데이터 분할, 모델 구조, 초기 파라미터, 배치 추출,
학습 횟수와 평가 방법을 맞춘다. 이전 학습을 이어서 실행한 모델은 같은
초기 상태에서 새로 시작한 모델과 다른 조건이다.

학습률을 낮추면서 학습 횟수도 늘렸다면 손실 감소에는 두 변화가 섞여 있다.
학습률 감소의 추가 효과를 보려면 같은 중간 상태에서 원래 학습률로 같은
횟수만큼 더 학습한 조건과 비교해야 한다. 문맥 길이와 은닉 유닛 수를
동시에 바꾼 경우도 각 변화의 기여를 따로 구분하기 어렵다.

직접 연결을 추가하는 구조 비교에서는 연결과 함께 파라미터 수도 늘어난다.
이는 직접 연결을 추가한 전체 변경의 비교이며, 같은 파라미터 수에서 그
연결 방식만의 효과를 분리한 실험은 아니다.

### train, dev, test의 역할

train은 파라미터 갱신에 사용한다. dev는 갱신에 쓰지 않은 데이터에서
손실을 확인하고 설정을 선택하는 데 쓴다. train 손실만 낮아지는지, dev도
함께 좋아지는지를 구분한다. dev 개선만으로 과적합이 전혀 없다고 증명되지는
않으며, dev를 반복해 보면서 설정을 고르면 그 선택에도 적응할 수 있다.
test는 설정 선택에 사용하지 않고 최종 평가를 위해 남겨 둔다.

### 관찰과 일반화의 구분

한 번의 실행에서 dev loss가 작아졌다면 그 실행에서의 개선은 관찰한 사실이다.
개선이 작고 반복 비교가 없다면 다른 초기화나 배치 순서에서도 일관될지는
알 수 없다. 고정 seed는 비교 조건을 맞추는 데 도움이 되지만 여러 seed의
결과를 대신하지 않는다. 차이가 작다는 이유만으로 효과가 없다고 단정하는
것도 피한다.

## 예제 또는 적용

문자 MLP 실습에서 같은 학습률과 반복 횟수로 비교한 dev loss는 직접 연결
없음 약 2.25183, 있음 약 2.24747이었다. 이번 실행에서는 약 0.00436 낮았다.
학습자는 작은 개선을 관찰했지만 단일 실험으로 일관된 이점을 확신할 수
없다고 해석했다. 추가 seed 비교는 수행하지 않았다.

별도의 추가 학습에서는 학습률을 낮춘 뒤 손실이 더 줄었다. 그러나 추가
학습 횟수도 함께 늘었으므로 학습률 감소만이 원인이라고 결론 내리지 않았다.
정확한 설정, 저장 출력의 경계와 평가 방식 차이는 실험 회고에 남긴다.

## 주의점

- 변동하는 미니배치 손실 한 번과 고정된 전체 dev 평가를 혼동하지 않는다.
- 실행 이름에 적힌 학습률과 실제 코드·로그의 설정이 다를 수 있다.
- 저장 출력은 파라미터 체크포인트나 현재 커널 상태의 증거가 아니다.
- test를 반복 확인해 좋은 설정을 고르면 최종 평가용으로 남겨 둔 역할을 잃는다.
