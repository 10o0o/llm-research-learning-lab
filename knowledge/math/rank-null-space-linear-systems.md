# 랭크, 영공간과 연립방정식의 해

## 핵심 요약

Rank는 행렬의 출력에 살아남은 독립 방향의 수다. 영공간 방향은 출력에서 사라지며, `rank(A)`와 확대행렬 `rank([A|b])`를 비교하면 `Ax = b`의 해가 유일한지, 무한히 많은지, 없는지 분류할 수 있다.

## 개념 정리

### 열공간, rank, 영공간

- 열공간은 `A`가 만들 수 있는 모든 출력의 집합이다.
- Rank는 열공간의 독립 방향 수다.
- 영공간은 `A @ x = 0`을 만족하는 모든 입력의 집합이다.

어떤 열이 다른 열의 선형결합이면 새로운 출력 방향을 추가하지 않으므로 rank가 증가하지 않는다. 열의 수가 `n`일 때 다음 관계가 성립한다.

```text
열 수 = rank(A) + 영공간 차원
```

0이 아닌 영공간 벡터 `c`가 있으면 서로 다른 입력 `x`와 `x + c`가 같은 출력으로 간다.

$$
A(\mathbf{x}+\mathbf{c})=A\mathbf{x}+A\mathbf{c}=A\mathbf{x}
$$

### 확대행렬로 해 분류하기

`n`을 변수 수라고 할 때 해의 종류는 다음과 같다.

```text
rank(A) != rank([A|b])
-> b가 A의 열공간 밖에 있음
-> 해 없음

rank(A) == rank([A|b]) == n
-> b를 만들 수 있고 영공간에 자유 방향이 없음
-> 유일해

rank(A) == rank([A|b]) < n
-> b를 만들 수 있지만 영공간에 자유 방향이 남음
-> 무한해
```

## 예제 또는 적용

```text
A = [[1, 2],
     [2, 4]]
```

둘째 열이 첫째 열의 2배이므로 `rank(A) = 1`이다. `c = [-2, 1]`이면 `A @ c = [0, 0]`이므로 영공간 차원은 `2 - 1 = 1`이다.

- `b = [3, 6]`은 열공간 안에 있어 해가 무한히 많다.
- `b = [3, 7]`은 열공간 밖에 있어 해가 없다.

## 주의점

- 열의 개수와 독립 방향의 개수를 같다고 가정하지 않는다. 종속된 열은 rank를 늘리지 않는다.
- `np.linalg.solve`의 성공 여부만으로 무한해와 해 없음을 구분하지 않는다. 먼저 `rank(A)`와 `rank([A|b])`를 비교한다.
