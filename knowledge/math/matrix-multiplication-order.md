# 행렬 곱의 순서와 특수 행렬

## 핵심 요약

행렬 곱은 일반적으로 순서를 바꾸면 결과가 달라진다. 특히 방향별 스케일 조정과 성분 혼합은 적용 순서에 따라 서로 다른 변환이 된다.

## 개념 정리

### 특수 행렬의 작용

- 단위행렬 `I`는 곱해도 값을 바꾸지 않는다.
- 대각행렬은 각 성분을 서로 섞지 않고 대각 원소만큼 독립적으로 확대·축소하거나 부호를 바꾼다.
- 대칭행렬은 전치해도 자기 자신과 같은 행렬이다.
- 모든 대각행렬은 대칭행렬이지만, 일반 대칭행렬은 대각선 밖의 값으로 성분을 섞을 수 있다.

### 곱셈 순서

행렬 곱은 앞 행렬의 행과 뒤 행렬의 열을 짝지어 계산하므로, 순서를 바꾸면 일반적으로 다른 조합을 계산한다.

```text
A @ B != B @ A
```

방향마다 배율이 다른 대각행렬 `D`와 성분을 섞는 행렬 `S`를 함께 적용하면, 먼저 섞은 뒤 스케일하는 경우와 먼저 스케일한 뒤 섞는 경우에 서로 다른 성분이 확대·축소된다.

대칭행렬이라는 성질은 `A.T == A`를 뜻할 뿐, 두 대칭행렬이 서로 교환된다는 뜻은 아니다.

### 순서를 바꿔도 같은 경우

`cI`처럼 모든 방향을 같은 비율 `c`로 조정하는 행렬은 어떤 행렬과도 교환된다.

```text
(cI) @ A = cA
A @ (cI) = cA
```

### 곱의 전치

행렬 곱을 전치하면 각 행렬을 전치할 뿐 아니라 곱하는 순서도 뒤집어야 한다.

```text
(A @ B).T = B.T @ A.T
```

## 예제 또는 적용

다음 예제에서 `D`와 `S`는 모두 대칭행렬이지만 곱 순서를 바꾼 결과는 다르다.

```text
x @ D @ S = [5.5, 6.5]
x @ S @ D = [3.0, 1.5]
```

`D`가 두 방향을 각각 `3`배와 `0.5`배로 다르게 조정하기 때문에, `S`로 성분을 섞기 전과 후에 적용한 결과가 달라진다.

## 주의점

- `A @ B != B @ A`는 일반적인 성질이며, 모든 행렬 쌍에서 반드시 다르다는 뜻은 아니다.
- 대칭행렬끼리도 항상 교환되는 것은 아니다.
- 대각행렬이라는 이유만으로 일반 행렬과 교환된다고 판단할 수 없다.
