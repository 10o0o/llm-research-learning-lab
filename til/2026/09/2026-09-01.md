## 오늘의 학습

### RNN의 이전 hidden state와 parameter sharing

RNN은 이전 위치의 hidden state를 다음 위치로 전달하고, 같은 recurrent parameter를 모든 토큰 위치에서 재사용한다.

성립 조건·작동 원리·한계: 순서가 있는 입력에서 앞선 정보를 이어 주지만, 오래전 정보는 같은 recurrent 경로를 반복해서 지나며 약해지거나 커질 수 있다.

학습 과정과 확인: 이전 hidden state 항의 역할과 모든 위치에서 계수가 공유된다는 점을 구분해 설명했다.

### LSTM gate와 cell state

LSTM은 hidden state와 별도의 cell state를 함께 이어 가며, gate로 기존 memory의 보존·새 정보 기록·hidden으로의 노출을 조절한다.

성립 조건·작동 원리·한계: 긴 recurrent path에서는 먼 정보의 영향이 반복 곱셈으로 줄어들 수 있다. LSTM의 forget gate는 보존량, input gate는 기록량, output gate는 노출량을 조절하지만 항상 기억을 보장하지는 않는다.

학습 과정과 확인: 새 후보 정보를 얼마나 쓸지와 완성된 cell state 중 hidden output으로 노출할 양을 구분해 설명했다.

### output, h_n, c_n의 역할 차이

batch-first recurrent API에서 output은 모든 토큰 위치의 hidden result를 보존하고, h_n은 마지막 hidden state, c_n은 마지막 cell state를 보존한다.

성립 조건·작동 원리·한계: 문장 전체 분류는 마지막 hidden state를 readout에 쓰고, 토큰별 태깅처럼 모든 위치의 결과가 필요한 task는 output 전체를 사용한다.

학습 과정과 확인: output에 sequence 축이 남는 이유와 마지막 hidden·cell state의 역할을 구분해 설명했다.

### SequenceClassifier의 forward data flow

SequenceClassifier는 `(batch, steps, input)` 입력을 위치별 cell 호출로 처리하고, 마지막 hidden state를 linear readout에 넣어 `(batch, classes)` logits를 만든다.

성립 조건·작동 원리·한계: RNN은 다음 위치로 hidden state만 전달하고 LSTM은 hidden state와 cell state를 함께 전달한다. readout은 raw 마지막 토큰이 아니라 sequence를 처리한 뒤의 hidden state를 사용해야 한다.

학습 과정과 확인: RNN과 LSTM cell의 서로 다른 state 인자를 반영해 forward loop와 마지막 hidden readout을 직접 구현하고 실행했다.

### 동일 조건 sequence train/eval과 baseline 비교

학습은 `zero_grad → forward → loss → backward → step` 순서로 진행하고, 평가는 gradient 없이 logits의 class 축 argmax와 label을 비교해 accuracy를 계산한다.

성립 조건·작동 원리·한계: 모델 비교에서는 generated data, split, hidden size, readout, optimizer, learning rate, epoch budget을 맞춰야 한다. 하나의 synthetic dataset 결과는 일반적인 architecture 우위를 증명하지 않는다.

학습 과정과 확인: manual RNN/LSTM, 마지막 토큰 linear baseline, loss, train loop, evaluation을 직접 연결했다. held-out 비교에서 RNN과 LSTM accuracy는 1.0, baseline accuracy는 0.53125였고, 마지막 원본 토큰만 읽으면 앞쪽 단서를 사용할 수 없음을 해석했다.
