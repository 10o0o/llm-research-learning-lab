## 오늘의 학습

### 다중분류 모델의 forward와 Tensor Shape

deterministic synthetic 다중분류 데이터를 만들고 train/validation을 분리했다. 작은 `nn.Module`의 `forward`에서 `nn.Linear(2, 3)`을 사용해 입력 feature 2개를 3개 class의 raw logits로 변환했다.

- 전체 입력 `X`: `(9, 2)`
- 학습 입력 `train_X`: `(6, 2)`
- 검증 입력 `valid_X`: `(3, 2)`
- `fc.weight`: `(3, 2)`
- `fc.bias`: `(3,)`
- logits: `(batch, 3)`

입력 feature 수를 2개에서 3개로 바꾸는 전이도 실행했다. 이때 새 입력은 `(N, 3)`, 새 weight는 `(3, 3)`, class 수가 그대로 3이므로 logits는 `(batch, 3)`으로 유지된다.

### Cross-Entropy와 학습·검증 흐름

`CrossEntropyLoss`에는 softmax를 직접 적용하지 않고 raw logits를 전달한다. logits는 `(B, C)`인 실수 Tensor이고, target은 `(B,)`인 `torch.long` class index이며 각 값은 `0 <= target < C` 범위에 있어야 한다.

학습 순서는 다음과 같다.

```text
zero_grad → forward → loss → backward → step
```

검증에서는 `model.eval()`과 `torch.no_grad()` 아래에서 validation loss를 계산하고, `logits.argmax(dim=1)`과 정답을 비교해 accuracy를 계산한다. 가장 많이 등장하는 class를 항상 예측하는 baseline도 계산해 모델 accuracy와 비교했다.

### Autograd와 parameter update

model의 weight와 bias는 `requires_grad=True`인 학습 parameter이고, 입력 feature와 class label은 보통 `requires_grad=False`이다. 입력이 gradient를 요구하지 않아도 parameter가 gradient를 요구하므로 loss에서 parameter까지의 계산 그래프가 만들어진다.

`loss.backward()`는 loss에 gradient를 저장하는 것이 아니라 parameter까지 gradient를 전파한다. 계산된 gradient는 `model.fc.weight.grad`와 `model.fc.bias.grad`에 저장되며, optimizer는 `model.parameters()`로 전달받은 parameter를 `step()`에서 업데이트한다.

## 배운 점

- 직접 구현하고 실행한 학습 loop에서 train loss가 감소했다.
- validation accuracy가 baseline보다 향상되었다.
- feature 수를 변경해도 입력 차원과 `nn.Linear`의 weight 차원을 함께 바꾸면 같은 forward·loss·backward 흐름을 유지할 수 있었다.
- `zero_grad()`는 이전 step의 gradient 누적을 제거하고, `no_grad()`는 해당 블록의 계산 그래프 생성을 막으며, `detach()`는 특정 Tensor를 기존 계산 그래프에서 분리한다는 점을 구분했다.
