## 오늘의 학습

### 문제 선택과 학습 흐름

규칙이 명확한 분류는 비용이 가장 싸고 빠르므로 규칙 기반으로 시작한다. label과 데이터가 충분한 이미지 분류는 딥러닝으로 시작한다.

문제 정의와 평가 기준을 정한 뒤 데이터와 label을 준비하고 train/validation을 분리한다. 모델, loss, optimizer를 선택한 뒤 `forward → loss → backward → step`으로 학습한다. validation으로 성능을 확인하고 checkpoint를 저장한 뒤, 새 입력에 inference를 한다. validation은 학습 데이터가 아닌 새로운 데이터에 대한 예측이 잘 맞는지 확인하는 단계다.

`backward`는 loss로부터 각 parameter의 gradient를 계산해 `.grad`에 쌓고, `step`은 그 gradient로 parameter를 실제로 바꾼다. validation에서는 검증만 하며, checkpoint에는 model state와 학습 재개가 필요할 때 optimizer state도 저장한다.

### Tensor shape와 디버깅

`(B, C, H, W)`는 이미지 shape로, `B`는 batch 수, `C`는 RGB의 세 channel, `H`와 `W`는 높이와 너비의 pixel 수다. 주로 CNN을 사용한다. `(B, L, D)`에서 `L`은 문장 길이, `D`는 embedding 차원이며 Transformer를 쓴다. `(B, F)` 표 데이터에는 MLP를 사용한다.

batch 축을 첫 축에 유지해야 샘플별로 맞출 수 있다. shape 오류는 shape부터, CE target 오류는 dtype부터 확인한다. `Linear(4, 3)`에 input `(2, 5)`가 들어오면 `5`와 `4`를 비교한다. feature가 5개라면 `Linear(5, 3)`으로, 4개여야 한다면 input을 `(2, 4)`로 수정한다.

### 퍼셉트론과 MLP

결정 경계는 `x2 = 2 * x1 + 1`이고 class 1은 직선 아래쪽이다. `nn.Linear(3, 2)`의 weight shape는 `(2, 3)`, bias shape는 `(2,)`이며 batch input `(4, 3)`의 output shape는 `(4, 2)`다.

이미지 batch `(2, 1, 2, 3)`은 flatten 후 `(2, 6)`이 된다. 은닉층 `Linear(6, 4)`를 지나면 `(2, 4)`, 마지막 `Linear(4, 3)`을 지나면 `(2, 3)`이 된다. `__init__`에는 flatten, 은닉층, ReLU 등을 등록하고, `forward`에서는 flatten 뒤에 퍼셉트론 계산과 ReLU를 수행한다.

### 비선형성과 ReLU

ReLU가 없는 선형함수의 조합은 결국 하나의 선형 식 `a*x+b`로 표현될 수 있으므로 한 직선으로 표현된다. 그래서 XOR을 직선 하나로 나눌 수 없다. ReLU는 양수는 유지하고 음수는 0으로 바꾸며, 각 원소의 값만 바꾸므로 shape는 유지된다. 은닉층의 중간 표현을 꺾어 비선형 패턴을 만들기 위해 사용하고, 음수 구간의 gradient가 0이면 dead ReLU로 학습 신호가 거의 없어질 수 있다.

### 출력층과 loss 계약

다중 분류에서는 logits shape가 `(5, 3)`, target shape가 `(5,)` `long`이고 `CrossEntropyLoss`를 사용한다. 독립적인 여러 tag를 고르는 경우에는 target이 `(B, C)`로 바뀌고 dtype은 `float32`, loss는 `BCEWithLogitsLoss`가 된다.

Softmax는 exp를 적용해 각 값이 양수가 되고, 그 합으로 나누므로 전체 합이 1이 된다. 이진 분류에서 logits는 계산값 그대로이고, Sigmoid로 `probs` 확률을 구한 뒤 0.5 이상이면 `pred`를 1.0으로 둔다. target은 logits에 대응하도록 `(3, 1)`이고 `float32`를 사용한다.
