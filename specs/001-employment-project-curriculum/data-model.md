**기준**: [수정 명세](spec.md) · [계획](plan.md) · [설계 조사](research.md). **2026-10-19 사용자 승인 설계**다. 실제 반영 여부는 tasks와 구현 검증 결과로 확인한다.

## 조사 근거

[JD](research/jd-evidence.md), [교육과정](research/reference-curricula.md), [동향](research/trend-evidence.md)을 조회일·공식 URL·판본/원문 날짜·접근 한계와 함께 남긴다. JD는 필수/우대·연차/학위·지역·접수 상태를, 과정은 선수/실습/접근·선택 범위를 구별한다. 모르는 값은 미표시/불명이다. 직접 본문을 읽지 못한 JD는 직접 검토 표본에서 제외한다.

[선택 매핑](research/decision-matrix.md)은 이 관찰을 단위/역량·사용 자료 구간·직접 산출물/평가로 연결한 튜터의 판단이다. 기관 인증이나 최적 학습 순서/시간표로 부르지 않는다. 이후 실제 지원/학습 시 바뀔 수 있는 공고·API·자료 권리는 다시 확인한다.

## 구현 단위

AX-01~04, RE-01~04는 새로운 정적 참조다. 기존 P0~P5, CC/SRC/MOD/MA/PC의 의미를 재사용하거나 새 단위를 옛 milestone 완료로 환산하지 않는다. 현재 위치는 여전히 STATE 하나다.

모든 핵심 단위의 10개 요소는 **사용자 문제·구현 목적·이전/다음 연결·입출력·전체 흐름·학습자 직접 작업·관찰 결과·완료 기준·최소 선수·작업 중 보강 개념**이다. [학습 계약 C2](contracts/learning-contract.md#c2-모든-핵심-단위의-10개-안내-요소)에 구체화했고 승인 후 ROADMAP을 범위 기준으로 삼는다.

RE-03의 기본안은 post-training/evaluation이고 inference/systems는 같은 단위를 대체하는 대안이다. RE-02 자체 작은 LM과 공식 A1 역시 같은 구현의 대안이며 전부 수행하는 병렬 과정이 아니다. 새로운 선택은 실제 목표/선수/자원과 사용자 범위를 확인하며 일반 활동마다 반복 승인하지 않는다.

## 북마크 이행과 과거 보존

실제 적용 직전의 STATE 전체를 읽는다. 새 transition 문서에 ‘당시 북마크 인용·현재 재개 사용 금지’를 붙여 보존하고 상대 링크의 원 목적지와 도움·미작성·미확인 의미를 확인한다. 특히 Part 4 dlogprobs 도움/비교와 dprobs 이후 미작성, Part 3/MLP·MIT/MML/fast.ai의 미확인 경계를 유지한다. 기존 회고를 고쳐 새 이해·독립 성공을 만들지 않는다.

그 다음 STATE를 `AX / AX-01 작은 AI 업무 기능`의 현재 범위와 다음 독립 행동 하나로 이행한다. 첫 행동은 **튜터가 준비한 문의 자료의 식별자·본문을 읽어 입력 계약을 확인하는 코드를 직접 작성·실행**하는 것이다. 튜터는 맥락/흐름/최소 선수·환경/자료/빈 공간 준비를 맡으며 아직 준비·실행됐다고 기록하지 않는다. 실제 모델 접근이나 비용이 해결되지 않으면 해당 호출은 미실행으로 남긴다.

이행 순서는 **직전 근거 확인→과거 인용 보존→내용/링크/경계 검증→새 북마크→단일 재개 검증**이다. 한 번의 문서 이행이며 자동 상태 기계가 아니다. 적용 사이에 새 학습자 변경이나 충돌이 생기면 보존하고 사실을 확인한다. 승인 전 설계 단계에서는 기존 STATE와 운영 문서를 보존했으며, 사용자 승인 후 구현 단계에서 위 순서로 이행한다. 실제 적용·검증 결과는 [quickstart](quickstart.md)에서 확인한다.

## 역사적 catalog와 보류 자료

CURRICULUM 기존 4~8절의 성과/module·milestone catalog, source registry/hash·감사 판정·정정·제약·공백은 과거 참고 경계 안에서 본문을 보존한다. 새 앞부분이 현재 역량/자료 기준이며 과거의 필수·readiness·RNN/LSTM·P0~P5 표기는 현재 지시가 아님을 명시한다. 오래된 필수 문구를 숨은 관문으로 사용하지 않는다.

DEFERRED에는 제외 범위·이유·관찰 가능한 복귀 조건을 둔다. [research R6](research.md#r6-옛-의무의-새-역할)의 옛 의무 전체 표와 선택 매핑의 새 선택/보류를 반영한다. 선택 해제는 완료가 아니며 공식 과제 재선택 시 기존 정책·판본·비공개/명령/환경 경계를 유지한다.
