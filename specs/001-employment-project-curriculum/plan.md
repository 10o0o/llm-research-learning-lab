**실제 Git 브랜치**: `main` · **기능**: `001-employment-project-curriculum` · **작성/수정일**: 2026-10-19

**명세**: [수정 명세](spec.md) · **공식 Workflow Run**: `17fc341e` · **상태**: 2026-10-19 수정 명세·계획 사용자 승인. 승인된 문서/튜터 규칙 구현·검증 완료; 실제 학습 수행은 별도

## 요약

단기 목표는 AX/AI 애플리케이션 취업 준비다. **한 업무 서비스를 작은 AI 기능→데이터/검색→도구 workflow→평가·운영·포트폴리오로 발전시킨다.** 이후 **모델 학습 실험→작은 LM 하나→전문화 하나→독립 실험**으로 LLM Research Engineer에 필요한 깊이를 쌓는다. 수학·통계는 사용 전에 필요한 개념을 설명하고 코드·오류·실험에서 더 깊게 배운다.

사내비·TF-IDF·분류기·파인튜닝·LangChain은 사용자가 든 예시다. 이들을 필수 순서로 고정했던 이전 설계를 이 문서로 대체한다. 한국·미국 상세 JD 13개, 교육과정 10개, 공식 동향 8개를 비교했다. 상세 본문이 열리지 않은 한국 ATS 2개는 보조로 분리했다. 자료의 실제 관찰과 아래 경로 선택은 구별한다.

이 계획의 구현 대상은 학습 문서·튜터 규칙·관련 검증이다. 학습자가 만들 앱·모델·과제 답안을 이번 개편에서 작성하거나 실행하지 않는다. 승인 전에는 새 경로를 적용하지 않고 기존 STATE·학습 기록을 유지했다. 승인 후의 실제 적용·검증 결과는 [quickstart](quickstart.md)에서 구별한다.

## 승인된 실제 학습 경로

### 취업 우선: 하나의 업무 문의 처리 보조 서비스

기본 프로젝트는 **문의에서 필요한 사실과 누락 정보를 정리하고, 문서·업무 데이터로 근거 답변과 처리 초안을 만드는 서비스**다. 실제 고객/사내 자료나 외부 업무 변경은 기본 범위에 없다. 사내비 Q&A 재구현은 같은 역량을 배우는 대체 후보이며 프로젝트명부터 고정하지 않는다. 후보 선택 이유는 [매핑 2절](research/decision-matrix.md#2-기본-프로젝트-후보-비교)에 있다.

| 단위 | 직접 만들 작동 결과 | 핵심 개념·평가 | 다음으로 연결할 이유 |
| --- | --- | --- | --- |
| **AX-01 작은 AI 업무 기능** | 한 문의→구조화된 업무 초안의 작은 CLI/API. 단순 규칙/서식 baseline과 단일 LLM 호출을 비교 | Python/JSON/HTTP·입출력 검증·token/context, 정상/누락/범위 밖 사례·형식/내용 오류 | 모델에 없는 외부 근거가 필요하다는 한계를 AX-02에서 해결 |
| **AX-02 데이터·검색·근거** | 문서/DB에서 근거를 찾아 답변·기권으로 연결 | chunk/metadata·embedding·검색, 단순 sparse 대비 dense 또는 hybrid 한 비교. 검색 recall과 답변 근거/누락 분리 | 지식 답변만으로 해결되지 않는 조회·처리 흐름을 AX-03에서 연결 |
| **AX-03 도구와 제한된 workflow** | 업무 API/SQL 조회 도구 하나와 로컬 처리 초안/모의 상태 변경. 고정 workflow와 bounded single-agent 비교 | 도구 계약·상태·timeout/retry·멱등성·사람 확인·step 제한. 기본 framework는 LangGraph 하나 | 정상 데모를 넘어 실패/복구와 실제 서비스 경계를 AX-04에서 다룸 |
| **AX-04 서비스 품질·지원 근거** | API·저장·회귀·로컬 배포/컨테이너·실행 안내·데모와 자기 기여 설명 | 권한/PII·관측성·실패 처리·품질/지연/비용. 실제 배포·운영과 로컬 확인 구별 | 읽은 실제 JD와 본인 산출물을 대조하고 필요한 공백만 보완 |

권고 순서는 위와 같다. 재현·입력 검증·오류 처리·평가는 AX-01부터 시작하며 AX-04까지 미루지 않는다. 수업 전 목적·앞뒤 흐름·입출력·사용 자료를 설명한 뒤 학습자가 코드를 쓴다. 단위별 안내 요소 10개와 실행/해석 기준은 [학습 계약](contracts/learning-contract.md)에 구체화했다.

**지원 자료의 두 경계**를 구별한다. AX-01의 작은 작동 기능에 문제·직접 기능·평가/실패·재현 조건·기여/도움·주장 한계의 여섯 설명을 갖추면 조기 공고 비교 자료로 쓸 수 있다. 주 포트폴리오 목표는 AX-01~04를 연결한 하나의 서비스다. 어떤 경계도 실제 경력·학위 요건이나 채용 합격을 보장하지 않는다. 장기 RE 과정이나 선택 파인튜닝이 끝날 때까지 지원 준비를 미루지 않는다.

**기술 선택**: Python 기반 API/저장/테스트가 중심이고 FastAPI·SQLite·pytest·로컬 컨테이너를 기본 후보로 둔다. 사용 직전에 공식 API와 현재 환경의 호환성을 확인한다. 프레임워크는 AX-03에서 상태·도구 책임을 이해하기 위해 LangGraph 하나를 선택하는 기본안이다. LangChain 전체→LangGraph 전체→ADK 전체 순회는 하지 않는다. TF-IDF는 AX-02의 baseline 후보이며 분류기·분류 파인튜닝·MCP는 문제/공고에 필요한 선택 확장이다. 채택·보류 이유는 [매핑 4절](research/decision-matrix.md#4-사용자의-예시와-유행-기술의-역할)을 따른다.

### 장기: 모델과 연구로 깊이를 늘리는 네 단위

취업 이후에만 배울 수 있다는 뜻은 아니지만 당분간 AX와 지원 준비가 우선이다. 아래는 빈칸으로 남겨둔 미래 목표가 아니라 자료·산출물·진입 근거를 정한 후속 경로다. 네 단위 전체가 첫 취업의 선수는 아니다.

| 단위 | 목적과 직접 산출물 | 선택 자료 | 의존 개념·다음 진입 근거 |
| --- | --- | --- | --- |
| **RE-01 모델 학습과 신뢰할 실험** | 소형 신경망의 data→train→validation 실험, 직접 training loop와 오류 진단. 기존 MLP 산출물 활용; 이미 증명한 내용을 반복 수강하지 않음 | MIT 6.S191 **2026** DL 기초, HF LLM Course 학습/데이터 절; MML/MIT 확률·ISLP는 공백별 보조 | tensor/loss·gradient·최적화·분리/누수·일반화. 학습자가 손실/shape·train/eval과 비교 조건을 설명하고 실제 실행/해석한 근거로 RE-02 진입 |
| **RE-02 작은 언어모델 하나** | tokenizer→embedding→causal attention/Transformer→next-token loss→학습/검증→생성/재개를 같은 LM에서 연결 | CS336 **Spring 2026** tokenization/PyTorch/architecture/data/eval 설명, HF tokenizers 보조 | 조건부확률·행렬·softmax/CE·mask와 계산/메모리. 제한 corpus에서 실제 train/validation·생성·checkpoint를 해석하고 데이터/계약을 추적하면 RE-03 진입 |
| **RE-03 전문화 하나: 기본안 post-training/evaluation** | 한 base model과 SFT/PEFT 결과를 같은 held-out 과업에서 비교. 데이터/형식/학습 신호·오류·자원 해석 | HF smol-course의 chat templates·SFT/PEFT·domain evaluation, HF LLM 관련 장, CS336 후속학습 설명 | 모델/데이터 권리·실행 자원, chat/loss mask·contamination·통제 비교. 질문·baseline·변경 요인·남은 실패를 정리하면 RE-04 진입 |
| **RE-04 질문 하나의 독립 실험·재현** | 실제 읽은 논문의 제한된 실험 또는 RE-03 오류 질문 하나의 baseline·통제·ablation·변동·실패 보고서 | 선택 전문화의 공식 설명과 실제 원문을 확인한 논문 하나; 개수 quota 없음 | 가설·비교 단위·불확실성·교란·재현성. 원논문/로컬 차이와 주장 한계를 설명하며 실제 연구/엔지니어 JD와 다시 대조 |

RE-02의 기본안은 **독립적인 자체 작은 LM 프로젝트 하나**다. 공식 A1을 고르면 이 구현을 **대체**하며 사전 전체 LM 재구현을 추가하지 않는다. 공식 A1의 기존 private clone/pin을 보존하고 재선택 시 정책·자원·별도 환경을 확인한다. 자체 프로젝트를 공식 A1 완료로 부르거나 공식 답안을 공개하지 않는다. 이번 계획에서 A1을 clone·download·실행하지 않는다.

RE-03은 **post-training/evaluation을 기본안**으로 제안한다. AX에서 관찰한 모델 행동/평가 문제를 데이터·학습 신호 실험으로 연결하기 쉽기 때문이다. 실제 지원 목표와 병목이 추론에 더 맞으면 **inference/systems 한 갈래로 대체**한다. 이때 prefill/decode·KV cache·batching 중 한 축과 품질/수치·지연/처리량·메모리를 통제 비교한다. CS336 A2의 학습 profiling과 serving은 다른 범위다. SFT·DPO/RLVR·추론·kernel·분산을 전부 의무화하지 않으며 유료/불가 자원은 별도 권한과 미수행으로 남긴다.

## 선수·평가·학습자 소유권

- **최소 선수**: 첫 코딩에는 Python 자료/함수·JSON/HTTP·LLM 입출력과 평가 사례의 의미를 먼저 설명한다. 검색 전에 벡터/embedding·근거, 도구 전에 계약/상태/부작용, 모델 학습 전에 tensor/loss·gradient·분리를 설명한다. 수학·통계 전체를 앞세우지 않고 [매핑 5절](research/decision-matrix.md#5-선수-개념을-배울-시점)의 사용처·오류에 연결한다.
- **평가**: 첫 기능부터 독립 사례·개발/최종 평가·중복·지표·오류를 다룬다. 검색 corpus 색인과 평가 질의/qrels는 구별한다. 분류·학습을 선택하면 전처리/모델 선택은 train/dev에 제한한다. 에이전트는 말로 한 성공과 실제 상태를 대조한다. 최종 자료를 보고 수정했으면 미사용 test라고 부르지 않는다.
- **직접 수행**: 학습자가 대상 코드·실행·첫 해석을 맡는다. 튜터는 목적/전후 흐름·공식 API의 관련 없는 작은 예제·허용된 환경/원자료 준비·실제 시도 검토를 맡는다. 대상 구현·정답/골격·공식 과제 솔루션은 제공하지 않는다. 실무 문서 참고와 대표/지연 회상을 별개로 다룬다.
- **성공의 의미**: 성능 향상은 모든 비교의 완료 필수 조건이 아니다. 실제 비교와 원인·한계를 해석한 실패도 근거다. 테스트 통과·튜터 설명·당일 실행을 독립 숙달·지연 기억·실제 운영·취업으로 승격하지 않는다.

정당화할 헌법 위반은 없다. 옛 과목 순서·전체 문제세트 의무와 고정 배분은 이번 변경 대상이며 보존할 소유권·자료 권리와 구별한다.

## 문서·작업 공간·북마크 이행

[문서 관계](data-model.md)를 기준으로 ROADMAP은 범위/단위, CURRICULUM은 선수/역량/자료, DEFERRED는 제외 이유/복귀 조건을 맡는다. README·USAGE는 요약/링크, AGENTS·study-session은 실행 규칙, STATE는 현재 재개 하나다. 조사 근거는 이 feature 아래에 두고 진행 추적 파일로 전환하지 않는다.

예정 학습 공간은 공개 가능한 `practice/ai-applications/workflow-assistant/`와 ignored `practice/private/workflow-assistant/`다. 원자료·평가 정답·가중치·큰 출력의 권리/공개 범위는 개별 확인한다. 2026-10-19 두 경로와 보존본 후보는 없었으나 실제 준비 때 충돌을 재확인한다. **이번 문서 개편 구현에서도 대상 코드·데이터·실습 폴더·모델을 미리 만들지 않는다.**

적용 직전 STATE 원문 전체를 새 `practice/reviews/curriculum-transition.md`에 ‘당시 북마크 인용·현재 재개 사용 금지’로 한 번 보존한다. 상대 링크의 실제 목적지와 기존 미완료/도움 의미를 확인한 뒤 현재 STATE를 `AX / AX-01`의 다음 행동 하나로 바꾼다. 기존 회고·노트북은 수정하지 않는다.

첫 독립 행동은 **튜터가 준비한 공개 가능 문의 자료에서 식별자·문의 본문을 읽어 입력 계약을 확인하는 처리 코드를 직접 작성·실행하는 것**이다. 이는 AX-01의 구조화 초안 흐름을 만드는 첫 작은 구현이다. 튜터가 문제·출력 목적·흐름·최소 개념을 설명하고 환경/자료/빈 작업 공간을 준비한다. 실제 모델 접근·비용이 해결되지 않았다면 모델 호출은 미실행으로 남기며 허위 출력으로 완료하지 않는다. 별도 긴 기획 답안이나 수학 전체 진단을 시작 관문으로 요구하지 않는다.

AGENTS는 실제 실행에서 관찰한 길이 잘림을 해결하도록 핵심·필독을 앞에 두고 **루트 12 KiB 이내**의 내부 예산으로 정리한다. 상세 준비·근거·과제·기록 정책은 새 `.agents/references/learning-policies.md` 한 파일로 옮기고 명시적으로 읽도록 한다. `CLAUDE.md -> AGENTS.md` symlink와 이동한 절 링크를 유지한다. 파일 크기/링크 검사와 현재 도구의 실제 필독 확인을 구별하며 전역 도구 설정을 바꾸지 않는다.

## 구현 순서와 검증

1. 승인 후 적용 직전 트리·STATE·기존 근거·충돌을 다시 확인하고 일회성 북마크 보존본을 먼저 작성/검증한다.
2. ROADMAP의 AX/RE 단위와 CURRICULUM의 자료/선수·DEFERRED의 옛 의무 재역할을 함께 반영한다. 과거 catalog·감사 본문을 보존한다.
3. AGENTS/상세 정책·study-session·사용 안내·하위 실행 문서를 맞춘다. 기존 과목의 숨은 필수 gate를 제거하고 준비/소유권/과제/기록 권한은 유지한다.
4. 검사를 새 계약으로 이행하고 STATE는 보존본 확인 후 다음 행동 하나로 전환한다. 일반 재개·문서 도움·선수 공백·오류·미개선·권리/비용·공식 과제 재선택을 검토한다.
5. [quickstart](quickstart.md)의 보존·링크·구조·검사·응답·필독 확인을 수행한다. 실제 학습/취업 근거는 별도이며 커밋·푸시·배포는 하지 않는다.

기존 순서/시간/Phase별 과제 고정 검사는 새 AX/RE 연결·근거 추적·선수 사용처·선택/보류의 정합성으로 대체한다. 준비 책임·대상 답안 금지·공개 답안/CS336·단일 STATE·조용한 북마크·종료·자료 감사/registry 보존 검사는 계속 검증한다. 후속 구현의 필수 명령은 `uv run --frozen pytest -q tests .agents/skills`, `uv lock --check`, `git diff --check`다. 정적 검사는 교육 효과를 증명하지 않는다.

## 계획 단계의 실제 완료 경계

공식 clarify/setup-plan 절차로 같은 feature를 사용해 사용자 보정을 명세에 반영하고 재조사·설계한다. `.specify/extensions.yml`은 없어 전/후 clarify·plan hook은 없다. 저장 후 파일·출처/링크·범위·명세 대응을 검증하며 그 결과는 quickstart에 기록한다.

공식 Run은 `17fc341e`다. 계획 단계에서는 `review-plan/paused`를 유지했고, 2026-10-19 사용자 응답 “승인할게”로 수정 명세·계획 검토를 통과했다. 기존 초기 입력의 예시 고정 해석은 공식 `specify workflow resume --input`으로 갱신하되 비대화식 gate에서 다시 정지하고 승인 선택은 전달하지 않는다. engine 상태를 수동으로 고치거나 기존 계획을 승인해 수정 단계를 통과하지 않는다. 실제 wrapper 재개는 `bash scripts/speckit-workflow.sh status 17fc341e`로 확인 후 `bash scripts/speckit-workflow.sh resume 17fc341e`를 사용하며, 수정본 승인 후에만 gate를 통과한다.

승인에 따라 tasks→정합성 검토→운영 문서/STATE 이행·튜터 규칙 구현·검증으로 이어간다. 학습자 앱/모델 구현·실습 실행·커밋·푸시·유료 실행은 이번 개편에 포함하지 않는다.
