# 수업 개선 후 검증 결과

2026-10-23. 대상은 [채택한 수업 개선 설계](../tutoring-redesign-2026-10-23.md)와 현재 AX-03의 수업 준비다. 현재 세션의 튜터가 저장 파일·실행 기록을 확인하고 허용된 지원 코드와 저장소 검사를 실행했다.

**운영 문서와 제공 코드의 검증은 통과했다. 실제 수업 효과는 아직 판정할 수 없다.** 개선 후 학습자의 직접 구현·실행·첫 해석이 없으며, 독립된 새 모델 대화도 실행하지 않았다. 아래 결과를 이해·효율 향상·독립 숙달·지연 기억의 증거로 바꾸지 않는다.

## 실행·확인한 범위

| 대상 | 방법과 실제 관찰 | 입증하지 않는 것 |
| --- | --- | --- |
| 제공된 초안 함수 | 가상 입력 6가지: 잠김·활성 상태는 초안을 반환하고, 조회 결과 없음·알 수 없는 상태·빈 ID·빈 본문은 `ValueError`로 거절했다. | 학습자의 독립 구현·이해 |
| 조회값 재사용·부작용 경계 | 조회 함수를 호출하면 실패하도록 대체하고, 파일·네트워크·하위 프로세스 및 주요 파일 변경 동작을 audit hook으로 차단했다. 여섯 입력 모두 해당 동작 없이 종료했고 정상 반환 상태는 초안이었다. | 본 흐름에 연결한 뒤의 동작·실제 계정 시스템 전체의 안전성 |
| 기존 제공 시연 | 기존 `check_draft.py`를 실제 실행해 마지막 성공 메시지와 정상 종료를 확인했다. | 학습자의 첫 실행·해석 |
| 남은 연결 구현 | 현재 `run_inquiry`의 계정 조회 호출 위치는 하나이고 초안 함수 호출은 없다. 기존 CLI의 `--help`는 정상 종료했다. | 초안 미리보기 전체 기능 완성·새 CLI 경로 실행 |
| 기존 실행 기록 | 저장된 101회 실행은 문의 ID 18개에 해당한다. 실제 계정 조회 결과가 들어 있는 기록은 8개다. | 101개의 독립 사례·개선 후 새 수업 결과 |
| 원본 보존 | 사전에 확인한 코드·가상 원자료·실행 기록·설정 등 40개 파일의 SHA-256이 검증 후에도 같았다. | 해당 파일 전부의 이번 공개 커밋 포함 |

지원 함수 검증은 설치·모델 호출·대상 기능 대행 없이 수행했다. 검증용 스크립트와 상세 결과는 저장소 밖 임시 공간에 두었다. 학습자가 연결할 기능을 대신 완성하거나 기존 실행 기록에 새 성공을 추가하지 않았다. 가상 문의·계정 원문도 공개 문서에 복사하지 않았다.

## 공개할 변경의 재현 검사

현재 작업 트리에서 `uv run --frozen pytest -q tests .agents/skills`는 **104 passed**, `uv lock --check`와 스킬 구조 검사는 정상 종료했다.

현재 Git 기준판에 이번에 공개할 문서·스킬·관련 계약 검사 변경만 덮어쓴 임시 사본도 만들었다. 기존 미추적 실습 코드·별도 CLI 검사·개인 설정·의존성 변경은 포함하지 않았다. 그 사본에서 기존 lab Python 환경으로 `python -m pytest -q tests .agents/skills`를 실행한 결과는 **100 passed**, 사본의 `uv lock --check`도 정상 종료했다. 새 의존성을 설치한 독립 환경 실험은 아니다.

104와 100의 차이는 이번 변경과 별도로 작업 트리에 있던 CLI 입력 검사 4개다. 검사 개수는 수업 사례 수나 학습 점수가 아니다. 실제 모델 응답의 지침 준수·답변 품질을 이 검사들로 확인했다고 표현하지 않는다.

공개 사본의 링크 검사에서는 미추적 로컬 실습 파일을 가리키는 링크 두 개가 실패했다. 작업 트리에는 파일이 있지만 공개할 Git 사본에는 없다는 원인을 확인하고, 설계의 해당 부분을 로컬 코드에 대한 관찰로 명시했다. 이 문제를 해결하기 위해 실습 코드까지 공개 범위에 추가하지 않았다.

## 실제 수업에서 아직 필요한 근거

| 판단할 내용 | 지금 확인할 수 없는 이유 | 다음 실제 활동에서 볼 것 |
| --- | --- | --- |
| 목적·흐름 이해 | 개선 후 학습자 해석이 없다. | 초안과 모델 답변의 차이, 기존 조회값을 사용하는 이유가 코드·출력 해석에 나타나는가. |
| 부수 작업 부담 | 기능 단위 운영·지원 분담은 문서에만 반영됐다. | 옵션·표시·문서 작업을 별도 과제로 계속 나누거나 같은 준비 복사를 요구하는가. |
| 구현·실행·피드백 연결 | 제공 함수는 실행됐으나 본 흐름 연결은 미작성이다. | 요청·미요청·조회값 부재를 한 기능에서 직접 실행하고 첫 해석 후 실제 피드백을 받는가. |
| 충분한 답 뒤 진도 | 작성자의 의미 검토만 있고 새 모델 대화 비교가 없다. | 이미 충분한 판단을 다시 제출시키지 않고 관련 다음 활동으로 연결하는가. |
| 이후 응용·기억 | 개선 후 독립 시도나 시간이 지난 실제 응용이 없다. | 이후 승인된 관련 기능이나 요청한 회상에서 관찰한다. |

관찰은 [STATE](../../../STATE.md)의 기존 초안 미리보기 기능 재개와 그다음 연결 활동에서 한다. 별도 준비도 시험·즉시 백지 재시험·추가 숙제·자동 일정·진도표는 만들지 않는다. 관찰 기회가 없으므로 효과가 없다고 판정하지 않으며, 개선됐다고도 판정하지 않는다. 과거에 측정하지 않은 시간·반복 질문·복사 횟수의 감소율은 계산하지 않았다.

## 미실행과 공개 범위

학습 중지 상태를 유지했다. [저장소 지침](../../../AGENTS.md#more-than-one-assistant)의 “추가 에이전트/작성자·매 응답 agent swarm은 만들지 않는다”에 따라 별도 튜터 에이전트 비교를 하지 않았다. 유료 실행과 실제 학습자 역할을 대신한 합성 실행도 없다. 초기 안내에서 예고한 모델 응답 비교는 수행 결과가 아니다.

이번 공개 범위는 수업 개선 설계·운영 문서·스킬·관련 계약 검사·이 검증 기록이다. 기존 실습 코드와 별도 설정·의존성 변경은 작업 트리에 보존한다. 실제 수업 효과 입증은 **미완료**이며 커밋·푸시의 성공으로 그 상태를 바꾸지 않는다.
