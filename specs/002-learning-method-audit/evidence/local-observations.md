## 2. 산출물의 제한된 읽기

### A-01 — 노트북

- **자료·방법**: inquiry-assistant.ipynb (`practice/ai-apps/inquiry-assistant.ipynb`, 로컬 확인 자료)를 `scripts/nbpeek.py --list`로 확인했다. 셀 7개 중 `--cells 1`, `--cells 2-5`의 관련 저장 코드·출력만 읽었다. 원본 전체 JSON·셀 0/6 본문을 읽거나 셀을 실행하지 않았다.
- **관찰**: 셀 1에는 입력 자료의 목록·항목·필드·문자열·공백 검사와 가상 문의 3개의 저장 출력이 있다. 셀 2의 식별자 검색·메시지 구성에는 튜터 참고 코드 표시가 있다. 이미 제공한 정보를 추가 확인 목록에 넣지 말라는 지시문이 있다.
- **관찰**: 셀 3/4에는 같은 개발 문의의 모델 응답·본문 표시가 있고 추가 확인 목록은 비어 있다. 셀 5에는 튜터 작성·검증 참고 코드 표시와 JSON 형식 검사 통과 출력이 있다.
- **해석**: 입력→식별자 선택→메시지→모델→형식 검사의 저장 증거다. 지시문 변경·실행·저장은 요청/STATE의 기여 구분과 일치한다. 저장 셀만으로 작성자의 독립성·내용 평가를 확정할 수 없다.
- **한계**: 변경 전 응답의 별도 보관, 새 사례의 모델 비교·최종 평가·새 커널 재현은 확인하지 않았다. 출력 시각을 학습 시각·시청 진도·무보조 수행으로 해석하지 않는다.

### A-02 — 반복 실행 스크립트

- **자료·방법**: inquiry_assistant.py (`practice/ai-apps/inquiry_assistant.py`, 로컬 확인 자료) 전체를 읽기만 했다. import·도움말·CLI도 실행하지 않았다.
- **관찰**: 파일 설명은 노트북의 입력 검사·검색·지시문·모델 요청·출력 검사를 재사용하고 튜터가 함수·CLI·기록 저장을 추가했다고 밝힌다. 문의 선택·형식 오류·출력 표시·누적 기록·조회 흐름이 있다.
- **해석**: 같은 준비 내용의 복붙을 줄이려는 도구가 존재한다. 양쪽 파일의 비슷한 지시문·검색·검사는 향후 중복 관리·기준 구현 비교가 필요한 이유다.
- **한계**: 존재·구조는 실제 모델 실행·자동평가·재현을 입증하지 않는다. 모의 검사 이력은 이번 요청/STATE에 제시된 사실이며 재실행하지 않았다. private 입력·실행 기록은 열지 않았다.

### A-03 — 사용자 제공 대화 사실

불만 문구, id 기반 검색 의도, 지시문 추가·실행, 튜터 지원, 최신 내용 판단과 정보가 적은 문의의 확인 기준은 이번 요청을 1차 근거로 사용한다. 별도 대화 로그를 찾아 빈도·시간·인과관계를 재구성하지 않았다. 파일과 일치한 부분만 A-01/02로 보강한다.

## 6. 명세 절차의 실제 상태

- 현재 `speckit-specify`를 직접 읽었다. `.specify/extensions.yml`은 없어 전·후 hook 대상이 없다.
- init-options는 sequential, 기존 feature는 001 하나다. 공식 `resolve-template.sh spec-template --json`으로 활성 템플릿을 해석해 002 하나를 만들었다. 브랜치 생성·전환은 하지 않았다.
- 상위 세션은 도우미 `check` 성공 후 요청 전체를 하나의 인수로 전달해 공식 Run `94c571a9`를 시작했다. 이전 001 Run `17fc341e`는 completed임을 별도로 확인했다.
- 명세 작성용 실행 내부의 재검사는 `Persistent Codex CLI is missing or points back to the workflow adapter.`로 실패했다. 이는 어댑터 내부 검사 결과이며 상위 Run 미시작·실패를 뜻하지 않는다. 중첩 run·설정 수리·추가 에이전트는 실행하지 않았다.
- 명세 작성 종료 후 상위 세션이 `status 94c571a9`를 다시 조회해 `Status: paused`, `Current: review-spec`, `specify: completed`를 확인했다. 명세 승인은 아직 없으며 승인 후 같은 Run을 재개한다.
- [초기 재감사](initial-review.md)는 상위 세션이 작성하고 명세 작성용 실행이 보존했다. 이후 상위 세션이 파일별로 순차 검토해 저장소 5전략·명세 범위·실제 워크플로 상태를 일치시켰다. 조사·잠정 제안은 아직 채택안이 아니다.
- 기존 STATE·pyproject·lock 변경과 미추적 실습을 보존한다. 스킬이 요구한 ignored 로컬 feature 포인터의 002 전환은 학습 상태·운영 변경과 구별한다.
