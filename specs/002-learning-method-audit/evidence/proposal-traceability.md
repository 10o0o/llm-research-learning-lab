# 요구·근거·제안·검증 추적표

상태: 계획 검토용. [research](../research.md)의 R-01~12와 [단위 계약](../contracts/unit-audit.md)의 U-AX/RE 8개가 최종 제안의 범위다. 비교표의 미채택 대안은 대안/조건이며 별도 채택 사실이 아니다. 아래 ID는 문서 참조이며 진도/점수 키가 아니다.

공식 근거 S는 [원문 구간·판본·9관점 카드](plan-source-supplement.md), C는 [기존 불만/관찰](local-observations.md), 현재 파일 확인은 [계획 로컬 검토](plan-local-review.md)에 있다. 각 S 참조는 해당 카드의 **관찰과 적용 해석 범위만** 사용한다. 현재 규칙의 기준은 [ROADMAP](../../../ROADMAP.md), [CURRICULUM](../../../CURRICULUM.md), [AGENTS](../../../AGENTS.md), [study-session](../../../.agents/skills/study-session/SKILL.md), [정책](../../../.agents/references/learning-policies.md), [헌법](../../../.specify/memory/constitution.md)이다. 실제 산출물은 노트북 관련 저장 셀 (`practice/ai-apps/inquiry-assistant.ipynb`, 로컬 확인 자료)과 제공 CLI (`practice/ai-apps/inquiry_assistant.py`, 로컬 확인 자료)를 뜻한다.

검증 V-A/B/C의 행동·실패·미실행 기준은 [quickstart](../quickstart.md)에 있다. 모든 실제 학습 효과와 후속 단위 수행은 이번에 미검증이다.

## 성공 기준의 현재 해석

SC-001~006/008 중 설계/비교/추적의 문서상 부분은 이 산출물로 검토할 수 있다. 실제 활동·출력·기여/재현·불편 감소와 연결되는 부분은 후속 관찰이 필요하다. **SC-007은 재개 후 실제 활동 관찰이므로 지금 달성 처리하지 않는다.** SC-009/010의 명세 단계 기록은 보존하고 현재 단계에는 승인된 계획 인계를 적용한다. 기존 명세의 요구/성공 기준 문구를 고쳐 단계 경계를 지우지 않는다.
