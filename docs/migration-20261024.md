## 역할 변경

- README: 시작 링크, STATE: 실제 현재 위치, ROADMAP: 단계 지도, CURRICULUM: 주교재·실습.
- AGENTS와 study-session: 안내·검토·도움·진도 기록만. 핵심 구현은 학습자 몫.
- TIL 폴더/템플릿/전용 스킬, 자동 finish-chapter, USAGE/DEFERRED와 중복 학습·기록 정책 제거.

- practice의 학습 코드·노트북, knowledge 개념 본문, archive 원본과 private 자료는 보존.
- 삭제된 TIL을 가리키던 출처 링크만 기준 커밋 URL로 교체. 새로운 이해나 성과를 추가하지 않음.
- 공개 검사에서 옛 문구·전체 카탈로그 해시 강제를 제거하고 링크·구조·공개 경계를 검사. 기존 학습 자료 보존은 변경 diff와 기준 커밋의 바이트 비교로 별도 확인.

전용 브랜치에만 반영한다. 강의 가입·과제 다운로드·새 프로젝트 생성·모델 실행은 수행하지 않는다.
