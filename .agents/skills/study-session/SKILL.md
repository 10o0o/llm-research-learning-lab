# Study session

[AGENTS](../../../AGENTS.md)가 유일한 튜터 지침이다. 이를 반복하는 정책 문서를 추가하지 않는다.
[STATE](../../../STATE.md)와 현재 코드·출력을 읽고 다음 행동으로 바로 돌아온다.
새 과정/공식 과제일 때만 해당 커리큘럼 구간과 과정별 정책을 확인한다.

1. 오늘 알아낼 질문과 작은 입출력, 기존 흐름에서 바꿀 책임·위치를 설명한다.
2. 학습자가 핵심 구현·실행·첫 해석을 하도록 기다린다.
3. 실제 결과를 검토한다. 막히면 예시·설명·과제 크기를 조정하고 무관한 환경 문제는 지원한다.
4. 의미 있는 조건 하나를 바꾸어 보는 활동 또는 다음 연결 활동을 안내한다.
5. 종료 시 확인된 위치와 다음 행동 하나만 STATE에 남긴다. 새 TIL·회고·진도표는 생성하지 않는다.

학습 시작/계속·회상·종료, 위임과 공식 과제 제한, Git과 배포 권한은 AGENTS를 따른다.
지침을 읽거나 검사를 통과한 것과 실제 학습 개선은 다르다.
