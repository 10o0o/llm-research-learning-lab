# Update Demonstrated Knowledge

Follow [AGENTS](../../../AGENTS.md) and [knowledge authoring rules](../../../knowledge/README.md).
Use the learner's explanation, calculation, or a specifically identified artifact they executed and interpreted.
Source text, tutor prose and STATE alone do not prove understanding.
Review existing notes before adding a concept; preserve the existing template and frontmatter for the website.
Correct only the demonstrated scope with authoritative sources. Do not force a new note if nothing useful changed.
Never copy private materials or official assignment solutions into public notes.
Validate changed notes with `scripts/validate_knowledge.py` in this skill and check the diff.
Report paths and checks; commit/push only within the user's actual authorization under AGENTS.
