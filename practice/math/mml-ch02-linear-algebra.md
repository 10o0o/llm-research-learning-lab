- 기준: Deisenroth, Faisal, Ong, *Mathematics for Machine Learning*, Cambridge University Press (2020), Draft 2024-01-15, Chapter 2.

- 방식: 본문에 근거한 대화 설명, 학습자의 손계산 답변과 피드백. 전체 연습문제 수행이나 무보조 숙달 완료를 뜻하지 않는다.

## 수행 범위와 확인 결과

부분공간, 선형독립, 기저와 랭크, 선형사상, 기저 변환, 상과 영공간,
단사·전사, 아핀 부분공간과 사상을 다뤘다. 기존 설명과 계산을 유지하며
부족한 부분을 본문과 공식 연습문제로 보강하는 로드맵 범위다.

- Exercise 2.9(a~d): 영벡터·덧셈·실수배 조건을 설명하고 판별을 시도했다.
  제곱 매개변수의 음수배 제한과 비동차 조건의 닫힘은 피드백으로 보완했다.
  정수 좌표의 실수배 반례와 행렬식 0 행렬 집합의 덧셈 반례 가능성을 직접 짚었다.
- Exercise 2.10(a~b): 선형결합 관계에 대한 안내 후 종속으로 교정했고,
  다른 경우에는 피벗 수를 근거로 독립이라고 답했다. 전체 행 연산은 제출되지 않았다.
  영벡터 조합·피벗 판별을 설명했지만, 조합 벡터 추가 시 독립성도 유지된다는
  주장은 생성 공간의 유지와 구분하도록 교정했다.
- Exercise 2.11: 선형결합 계수를 정확히 제시했다.
  Example 2.18에서 원래 피벗 열을 기저로 골랐으나 영공간 차원은 교정이 필요했다.
- Exercise 2.12: 교집합 조건 설정과 계수 관계를 안내받아 계산했다.
  최종 교집합 벡터와 기저 계산은 미완료이며, 요청에 따라 다음 절로 이동했다.
- Exercise 2.16(c~d): 영벡터의 출력으로 비선형을 판별했다.
  입력·출력 차원이 다르면 비선형이라는 판단은 피드백으로 교정했다.
- Exercise 2.17: 변환행렬과 소거를 시도했다. 원소·부호 오류, 상과 영공간의
  차원 및 피벗 열 해석에 설명이 필요했다. 전체 무보조 해결로 보지 않는다.
- Exercise 2.20(a~f): 기저 판별과 좌표 계산을 시도했다. 원래 기저의 열 배치,
  입력·출력 기저를 구분하는 이유, 합성 순서를 설명받았다.
  (d)의 계수 열과 (f)의 단계별·직접 좌표 계산은 정확히 제시했다.
  (e)의 한 원소는 교정했다. (a)의 그림 작성은 미확인이다.
- Exercise 2.19(a): 영공간이 영벡터뿐임을 직접 구했으나 상도 0차원이라는
  결론은 교정했다. 입력 집합인 영공간과 출력 집합인 상을 여러 예시로 보완했다.
- §2.8 회상: 평행이동과 곱한 뒤 더하기라는 설명을 직접 했다.
  아핀 공간을 1차원으로 제한한 점을 교정했고, 제시한 사상의 선형성·출력 공간
  판별은 막혀 해설로 보완했다. 해설 후 이해 응답은 독립 전이 성공이 아니다.

## 지식 노트와 도움의 범위

대화에서 학습자가 먼저 설명한 부분공간·독립성·아핀 개념을 초안으로 사용했다.
노트에는 교정된 참고 설명을 담았으며, 교정 내용을 전부 무보조로 설명했다는 뜻은 아니다.

- [벡터 부분공간](../../knowledge/math/vector-subspaces.md): 세션 중 요청으로 이미 기록한 내용을 유지했다.
- [선형독립과 생성 공간](../../knowledge/math/linear-independence-and-span.md): 독립성 판별 설명과 조합 벡터 추가에 대한 교정을 정리했다.
- [아핀 공간과 아핀 사상](../../knowledge/math/affine-spaces-and-mappings.md): 학습자의 평행이동·곱셈 후 덧셈 설명을 출발점으로 차원 제한과 선형성 구별을 교정했다.
- 기존 [선형변환과 기저](../../knowledge/math/linear-transformation-basis.md),
  [랭크와 영공간](../../knowledge/math/rank-null-space-linear-systems.md)은 참고 노트로 유지했다.
  노트의 존재를 이번 세션의 독립 이해 근거로 사용하지 않는다.
