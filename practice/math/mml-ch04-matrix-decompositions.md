## 기존 북마크의 관찰 기록

MML §4.1에서는 주어진 2×2 삼각행렬 분해를 직접 곱하고 원래 행렬과
분해된 행렬들의 행렬식이 모두 8임을 계산했다. `UL`의 대각합은 처음에
8로 잘못 계산해 해설로 7로 교정했으며, 삼각행렬의 행렬식이 대각 원소의
곱이므로 이를 통해 역행렬 존재 여부를 판단할 수 있다고 이후 설명했다.
대각합의 순환 불변성과 대각 원소가 0으로 바뀌는 경우는 해설을 거쳤으므로
전체 무보조 성공으로 보지 않는다.

MML §4.2의 정의와 Example 4.5 흐름을 다룬 뒤, 반복 고유값 3을 갖는
상삼각행렬의 특성다항식과 고유값을 직접 구했다. 처음에는 `B - 3I` 자체를
고유공간으로 적었으나 해설 후 고유방향 `[1, 0]`을 확인했고, 독립적인
고유방향이 하나뿐이라 가역인 고유벡터 행렬 `P`를 만들 수 없어 대각화할 수
없다고 설명했다. 고유공간은 대표 벡터 하나가 아니라 그 벡터가 생성하는
부분공간이라는 표기 구분은 교정이 필요했다.

## 재확인할 항목

- 튜터 해설 후 동의는 독립 회상 완료가 아니다.
- §4.1의 `tr(LU) = tr(UL)` 직접 계산과 순환 불변성은 해설 없이 다시 확인하지 않았다.
- §4.2에서 고유공간과 `B - λI` 행렬을 처음에 구분하지 못했고, 고유공간을 `span`으로 나타내는 표기는 피드백 후 교정했다.

## 이번 대화에서 확인한 설명과 계산

### 행렬식·고유공간·대각화

Figure 4.4에서 넓이 보존만으로 모양 보존을 판단할 수 없고, 회전은 정보를
보존하지만 차원 붕괴는 정보를 잃는다고 설명했다. 180도 회전행렬은 직접
적었으나 고유값의 부호와 고유벡터가 같은 직선 위에 남는다는 조건은 반복
교정했다. Example 4.7에서는 연결 유무와 한쪽 연결의 방향을 구분했고,
양방향 연결 여부가 덧셈 결과에 남는다는 점은 해설 후 계산했다.

전치행렬 곱의 양의 준정부호 성질을 변환 결과의 길이 제곱으로 설명했다.
정사각형이라는 사실만으로 대칭성을 주장한 부분과, 양의 정부호를 반박하려고
영벡터 입력을 고른 부분은 교정했다. 같은 열의 상쇄 입력은 힌트 뒤 구성했다.
스펙트럼 정리에서 정규직교 기저의 존재와 임의의 고유벡터 선택을 구분했다.
같은 고유값의 선형결합과 다른 고유값의 합에 대한 설명은 해설 후 확인했다.

대각화의 기호·좌표 변경·배율 역할은 여러 차례 재설명했다. 반복 곱에서
중간 역행렬의 상쇄와 대각행렬의 거듭제곱은 설명했으나, 입력 계수와
고유값 배율의 구분 및 부호가 교대하며 감소하는 성분은 해설로 구체화했다.
Figure 4.6의 넓이·둘레 조건과 대각합의 순환 불변성은 독립 설명 미확인이다.
PageRank의 고정 분포와 고유값 1은 연결했지만 주기적 복귀를 수렴으로
판단하여 교정했다.

### Cholesky와 SVD

Cholesky의 주어진 행렬·구할 인자·원소 비교 목적을 설명했다. 투영행렬에도
양의 대각 인자를 둘 수 있다는 판단은 교정했다. Example 4.10의 3차원 계산과
Example 4.11의 직접 계산은 수행하지 않았다.

SVD의 입력·출력 기저 역할을 설명하고, 한 특잇값이 0이면 해당 입력 기저
성분이 사라진다고 설명했다. 영화 행이 추가될 때 완전 SVD 인자 크기도
정확히 답했다. 전치행렬 곱을 정규직교 고유기저 선택과 연결했고, 고유값의
제곱근으로 특잇값을 구했다. 음수 출력 성분은 방향이고 특잇값은 길이라는
이유와 출력 벡터의 정규화는 직접 설명·계산했다. 영공간 방향이 존재하지
않는다는 표현, 고유값과 특잇값의 부호는 교정이 필요했다. 마지막 대각행렬
적용에서는 두 종류의 값을 정확히 답했으며 길이 배율이라는 이유는 보충했다.

Example 4.13은 단계별 안내 아래 전치행렬 곱과 특잇값 행렬, 나머지 두
오른쪽 특이벡터와 두 왼쪽 특이벡터를 직접 계산했다. 첫 고유벡터의 성분
부호는 피드백 뒤 수정했고 고유값 근의 부호는 해설로 교정했다. 전체 곱의
직접 재구성 검산은 하지 않았다.

### 근사와 공식 연습

영인 기여를 생략하는 정확한 분해와 작은 양의 특잇값을 버리는 근사를
구분했다. 외적과 rank-1 행렬의 크기는 SVD 인자 크기와 혼동하여 교정했다.
스펙트럴 노름의 수치 오차와 허용 오차에 필요한 항 수는 맞게 계산했고,
모든 단위 입력 중 최대라는 조건은 보충했다. Eckart–Young의 오차 하한
증명은 해설 후 동의 상태다. 평점 범위로 원소를 자르면 rank·최적성을
보장할 수 없다는 판단은 했으나 이유는 튜터 반례로 설명했다.

- Exercise 4.5: 가역성 판단은 모두 맞았고 두 대각행렬의 대각화 판단도
  맞았다. 나머지 대각화 판단, 고유공간과 행렬 자체, 영벡터와 고유벡터의
  구분은 피드백을 거쳤다.
- Exercise 4.8: 영공간 방향은 직접 구했다. 행 연산이 영공간은 보존하지만
  고유값은 일반적으로 보존하지 않는다는 점을 설명받았다. 나머지 고유값,
  특이벡터, SVD 인자와 재구성 검산은 사용자 요청으로 튜터가 계산했다.
  전체 독립 풀이로 기록하지 않는다.
- Exercise 4.10: 앞서 제공된 인자와 공식으로 rank-1 근사를 직접 계산했다.
  두 동일한 행이 만드는 행공간의 기저가 하나라는 이유로 rank를 설명했다.
- Exercise 4.11: 미수행 보류. 로드맵의 MML은 약점 보강용 reference이며
  장말 전체 증명이 필수라는 요구는 없음을 사용자와 확인했다.
- Exercise 4.1~4.4·4.6~4.7·4.9·4.12는 미수행이다. 특히 4.12는 본문의
  스펙트럴 노름 정리 증명 연습이다. 미수행을 완료로 처리하지 않으며,
  모든 문제 수행을 일괄적인 다음 장 진입 조건으로 두지도 않는다.

## 재개 시 구분할 한계

고유공간·대각화 조건, 고유값의 부호, 입력 계수와 배율, rank와 행렬 크기의
구분은 교정 후 설명과 독립 수행을 구분해 다시 볼 부분이다. 증명과
Cholesky 성립 조건을 해설 없이 복원했다고 판단하지 않는다. 과정은
공식 본문을 확인한 대화·손계산이며 코드 실행·대학 채점·전체 장 숙달이 아니다.

지식 노트는 대화에서 학습자가 작성한 설명을 초안으로 삼아 교정한 범위다.
SVD 인자와 방향·길이의 역할, 영 성분 생략과 근사 차이, 스펙트럴 오차의
계산을 반영한다. 영공간·대각화·Cholesky의 새로운 숙달 노트를 대신 만들지
않으며 기존 고유기저 노트의 존재를 현재 독립 설명의 증거로 사용하지 않는다.
