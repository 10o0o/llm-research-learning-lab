## 단변수 미분과 Taylor 근사

§5.1에서 음수 입력의 도함숫값과 입력 증가 시 출력 감소를 직접 정확히
설명했다. 일반 거듭제곱 미분의 이항전개 증명은 직접 수행하지 않았다.

Example 5.3에서 기준점의 여러 차수 도함숫값을 직접 구했다. Taylor
다항식을 최고차 변화항 하나로 해석한 부분은 교정했고, 전체 항 조립은
요청에 따라 튜터가 계산했다. 팩토리얼로 나누는 이유와 기준점의 도함수를
맞추는 목적은 재설명했으며 독립 설명은 미확인이다. Example 5.4에서는
주어진 고차 도함숫값의 항 계수는 정확히 구했지만 계수 결정 이유는
튜터 설명과 구분한다.

유한 차수의 도함수를 맞추는 근사가 모든 입력에서 원래 함수와 같지는
않다고 판단했다. 오차의 이유와 무한급수의 일치 조건은 튜터가 보충했다.

## 편미분과 연쇄법칙

Examples 5.5~5.8에서 단변수 합성함수, 두 입력의 편미분, 여러 중간값을
거치는 도함수를 직접 계산했다. 각 경로의 기여와 행벡터 gradient의
조립은 튜터가 보충했다. 변화율을 곱하는 이유에 대해서는 두 함수가
변한다는 설명을 제시했으며, 중간값을 거쳐 변화가 순차 전달된다는
인과관계는 튜터 해설을 거쳤다.

Gradient checking에서 두 입력을 동시에 바꾸면 다른 입력의 변화도
섞인다고 판단했다. 편미분 식에 다른 변수가 등장하기 때문이라는 설명은
실제로 두 입력을 함께 움직였기 때문이라고 교정했다.

## 야코비안과 행렬 입력

Example 5.9에서 성분을 미분하면 고정 계수가 남고 입력과 무관한 상수벡터는
미분에서 사라진다고 설명했다. 편미분들을 합산하려는 뜻이 아니라 배열해
나열하려는 뜻임을 명확히 했다. 입력·출력 성분과 행·열의 대응 및 전체
야코비안 크기는 교정이 필요했다.

Example 5.10에서는 함수의 실행 순서와 연쇄법칙 형태를 맞게 제시했다.
지수함수 미분을 설명한 뒤 바깥 함수의 두 편미분을 정확히 계산했다.
중간 함수의 한 도함수는 맞았지만 다른 도함수의 인자 표기는 불명확했다.
두 야코비안의 크기·곱 순서와 최종 조합은 튜터가 설명·계산했다.

Example 5.11에서는 입력특성 계수가 남는다는 점을 설명했다. 제곱 미분에서
두 배로 하는 대상을 매개변수로 이해한 부분은 현재 오차값으로 교정했다.
그 뒤 오차·입력특성·음수 배율을 반영한 구조를 직접 제시했고, 예측과
관측값이 일치하면 gradient가 영이라고 판단했다. 입력특성도 매개변수에
따라 변한다는 주장은 고정된 전달 민감도와 구분하도록 교정했다.
오차벡터의 전치와 미분 배열 크기는 튜터가 보충했다.

Examples 5.12~5.13에서는 출력 성분과 행렬 입력 원소를 구분하는 첨자
정의를 제시했다. 고정 입력벡터의 행렬곱을 펼친 뒤 다른 행의 원소로
미분하면 영, 같은 행이면 계수가 남는다고 설명했다. 행렬 제곱의
비대각 출력 편미분은 직접 구했고, 대각 출력의 거듭제곱 미분은 교정 후
수정했다. 남는 입력 성분의 열 번호, 출력·입력 네 축 배열의 구성은
튜터 설명을 거쳤다. 원소들을 열 순서로 쌓은 야코비안 표현에서는
입력 원소 수와 열 수를 연결했으며 전체 크기는 보충 설명 후 수정했다.

## 행렬 미분 항등식

§5.5의 이차식에서는 튜터가 스칼라 항으로 펼친 뒤 두 편미분을 정확히
구했다. 전치한 계수를 더하는 이유와 대칭 조건에 따른 단순화는 튜터가
설명했다. 고정 가중치를 둔 제곱오차 보충 예에서는 제곱 미분·가중치·
오차 변화율을 반영한 도함수를 정확히 제시했다. 고정 가중치의 역할과
행렬 공식 연결은 튜터가 보충했다.

전치 후에도 대각 위치가 유지되어 trace의 도함수가 같다고 설명하고
주어진 함수의 도함수를 정확히 계산했다. 사용한 대각행렬이라는 용어는
대각원소로 교정했다. 역행렬 미분은 가역 조건과 곱 순서를 설명받은 뒤
시도했으나 첫 원소 계산과 전체 음수 적용에 수정이 필요했고 독립 수정은
미확인이다. 행렬식 미분과 고정 벡터의 역행렬 이차식 등 나머지 항등식은
조건·출력·크기를 중심으로 튜터가 설명했다. 별도 직접 적용의 근거는 없다.

## 자동미분과 Hessian

§5.6에서 역전파를 입력 변화에 따른 손실 변화율로 설명했다가, 고정 입력과
학습 매개변수의 구분을 설명받았다. 이후 학습할 가중치의 손실 기울기를
구한다는 목적과 같은 가중치로 들어오는 경로의 기여를 더하는 규칙을
수정했다. 같은 가중치 변화가 두 경로를 함께 바꾸고 전체 손실이 합이라는
인과관계는 튜터가 보충했다.

Example 5.14의 중간값 재사용·공유 노드의 합산과 순방향·역방향 자동미분의
기울기 전달 방향은 튜터가 설명했다. 마지막 덧셈을 곱셈으로 바꾸는 경우에는
고정 계수의 편미분 원리를 보충한 뒤 각각의 국소 변화율을 맞게 제시했다.
전체 그래프 도함수를 독립 구성한 것으로 보지 않는다.

§5.7에서는 두 입력의 Hessian 예와 대각원소의 의미·대칭 조건을 튜터가
제시했다. 학습자는 비대각원소를 다른 변수가 해당 기울기에 미치는 영향으로
직접 설명했고, 두 입력의 곱 항을 없애면 그 영향도 없어져 비대각원소가
영이 된다고 이유를 제시했다. 이 설명을 혼합 편미분 개념 노트의 초안으로
사용한다. 전체 Hessian의 독립 계산과 대칭 조건의 회상은 따로 미확인이다.

## 다변수 Taylor 근사

§5.8과 Example 5.15의 함수값·gradient·이차 근사·수치 비교는 튜터가 제공했다.
학습자는 일차 변화율과 그 변화율의 변화율을 구분했지만, 근사함수의 의미와
계수의 구성은 이해되지 않았다고 명확히 표현했다. 기준점에서 함수값·기울기·
굴곡을 맞추는 목적, 입력 변화량, 제곱항과 혼합항의 계수는 튜터가 재설명했다.

한 입력을 기준점에 고정한 조건에서는 질문의 뜻을 재설명하고 두 대입식을
제공한 뒤, 원래 함수와 이차 근사가 같아질 것으로 판단했다. 차수에 따른
정확성의 이유와 삼차 보정항이 사라지는 연결은 튜터가 제시했다. 고차 미분
배열의 크기와 변화량을 곱해 스칼라 항으로 모으는 구조도 튜터 설명이다.
입력 변화량의 외적을 별도 행렬로 구성하는 것은 직접 다루지 않았다.
이해 응답만으로 계수·텐서 조립의 독립 회상을 확인하지 않는다.

## 남은 설명과 공개 기록의 한계

야코비안의 전체 크기·행/열 대응과 행렬 연쇄법칙 순서, 이차식에서 전치항이
생기는 이유, 역행렬 미분의 최종 부호, 공유 경로 합산의 인과관계,
Taylor 계수·고차 배열의 독립 구성은 다시 볼 부분이다. Hessian의 대각원소와
대칭 조건, 자동미분의 전체 그래프 조립도 튜터 설명과 독립 수행을 구분한다.

혼합 편미분의 의미와 곱 항 제거의 인과 설명은 학습자 초안이 있어 개념
노트에 반영했다. 다른 내용은 기존 도함수·자동미분 참고 노트의 존재나
계산 성공만으로 새로운 무보조 지식 초안으로 취급하지 않았다.
노트북 실행·공식 채점·전체 장 숙달을 확인한 기록이 아니다.
