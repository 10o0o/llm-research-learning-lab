# fast.ai 책 1장 — Your Deep Learning Journey 회고

정리일: 2026-09-22. 기준 자료는 fastbook의 01_intro.ipynb와
Practical Deep Learning for Coders 2022 Part 1 Lesson 1이다.
학습자의 명시적 결정으로 미완료를 남기고 Lesson 2·책 2장으로 이동한다.
챕터 전환은 공식 요구 전체 완료, 영상 전체 시청, 독립 회상 통과를 뜻하지 않는다.

## 보존과 원문 경계

원문·공식 코드·학습자 실행 결과가 섞인 `01_intro.ipynb`는 비공개 챕터
보관 영역의 `fastai-book01-intro.ipynb`에 바이트 그대로 복사했다.
책 원문과 사진은 공개 Git에 추가하지 않는다. 원문 노트북과 과거 설정 전
사본은 읽기 자료로 유지한다. 원문을 빈 셀로 지우지 않는다.
학습용 `lesson1-local.ipynb`는 모든 보관·노트 검증 후 빈 코드 셀로 초기화했다.
`main.ipynb`와 `recall.ipynb`는 이미 빈 상태라 중복 보관하거나 다시 초기화하지 않는다.
셀 번호는 보관본 기준 1부터 센다. 재실행 없이 저장 결과를 확인했다.

고양이·개 표에서 검증 손실은 감소했지만 오분류율은 초기 단계보다 약간
증가했다. loss와 오분류율이 같은 지표가 아니라는 설명에 사용했으며,
학습자가 혼자 이 차이를 설명한 것으로 기록하지 않는다.

분할 그림은 같은 대화에서 직접 확인했다. 넓은 영역의 대체적인 일치와
작은 물체·경계의 차이는 튜터가 보완했다. 사진별 관찰을 픽셀 정확도 측정으로
바꾸어 기록하지 않는다.

위젯 파일 선택이 작동하지 않아 사용자 요청으로 로컬 개 사진을 입력하도록
AI가 셀을 수정했다. 위젯 자체가 수리된 것은 아니다. 의존성·커널 설정과
파일 입력 연결은 AI 도움이며 학습과 예측 실행은 학습자가 했다.

## 학습자 설명에서 확인한 범위

- 검증 결과를 보고 반복해 설정을 선택하면 검증 세트에도 과적합할 수 있다.
  평가 데이터는 실제 사용 환경을 대표해야 한다.
- 해상도를 줄이면 계산 자원이 줄 수 있지만 특징 정보를 잃을 수 있다.
  체중 예측은 회귀이며 정답은 사진에 대응하는 수치여야 한다.
- 모델 가중치와 학습률·배치 크기는 역할이 다르다. 일정에 따라 자동으로
  줄어드는 학습률도 하이퍼파라미터다.
- 추천 노출이 클릭 수에 영향을 주므로 클릭 수 증가만으로 선호 증가를
  단정할 수 없다.
- GPU는 유사한 계산을 병렬 처리한다. 적은 사진의 미세조정은 이미 들인
  사전학습 계산을 활용하므로 큰 모델의 처음부터 학습과 자원 요구가 다르다.
- 사진과 대응하는 정답의 필요성, 여러 계산이 결합된 예측의 해석 어려움,
  픽셀별 정답·예측, 모델 구조와 가중치의 구분을 부분적으로 설명했다.

이 설명들은 대화의 학습자 초안에 근거한다. 해설 직후의 답변도 포함되므로
시간이 지난 뒤의 무보조 회상이나 챕터 전체 독립 설명을 보장하지 않는다.

## 설명으로 보완했고 독립 확인은 남은 부분

- loss 자체만큼 갱신한다는 혼동: gradient·학습률·optimizer 역할을 보완했다.
- Loss와 metric, head, CNN의 층별 특징과 사전학습의 최적값 보장 여부.
- 세 클래스에 해당 없음이 자동으로 추가된다는 오해와 입력 채널·출력 클래스의 구분.
- 집 단위 분할 선택은 맞았으나 클래스 균형이 이유라는 오해가 있었다.
  배경·조명 공유를 피한다는 설명은 튜터가 제공했다.
- y_range는 평점 저장소가 아니라 출력 범위라는 점, 파형과 스펙트로그램의 차이.
- 보편 근사 정리 이름은 회상하지 못했다. 단층의 표현 한계와 얕은 망의
  효율 문제, XOR, PDP 구성 요소와 역사도 해설로 보완했다.
- 자동 검증 분할은 API별로 다르며 테스트 세트가 자동 생성된다는 뜻이 아니다.

기존 knowledge에 관련 내용이 있어도 이번 답변의 혼동을 숨기거나
완전한 독립 이해로 간주하지 않는다. 근거 없는 개념을 새 숙달 노트로 추가하지 않았다.

## 미완료·미확인으로 남기는 공식 요구

- IMDb 전체 미세조정, 예시와 자기 리뷰 예측·해석. 저장된 셀 151의 예측은
  책의 기존 예시 출력이며 학습자의 실행 결과로 취급하지 않는다.
- 표 데이터 학습·해석(셀 160·162), 협업 필터링 학습·해석(셀 165·167).
  개념은 해설했으나 기존 책 출력은 실행 증거가 아니다.
- Stripped notebook 전체에서 실행 전 결과를 예상하는 과제.
- Jupyter 온라인 부록 전체. 기본 셀 조작 반복은 사용자가 원하지 않아
  생략했다. 부록 전체 수행으로 바꾸어 기록하지 않는다.
- Questionnaire 전체의 독립 답변. 문항별 일부는 대화로 확인하고 일부는
  튜터가 설명했으며 별도 전체 답안은 없다. 간단한 산술 셀의 당시 성공 출력도
  이번 저장본에서 새로 확인하지 않았으므로 억지로 재실행시키지 않았다.
- Further Research는 별도 심화 구간으로 미수행이다.

위 항목을 강제로 다시 수행시키는 대신 미완료 상태를 유지하고 이동한다.
새 커널에서 전체 셀을 순서대로 실행하는 재현성은 검증하지 않았다.
학습 종료 시점의 GPU 사용량·느린 원인은 측정하지 않았으며 CUDA 미사용이나
메모리 부족 때문이었다고 단정하지 않는다.
