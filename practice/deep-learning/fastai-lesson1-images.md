# fast.ai Lesson 1 — 이미지 분류 실습 회고

정리일: 2026-09-22. 기준은 Practical Deep Learning for Coders 2022 Part 1
Lesson 1과 공식 Is it a bird? 실습이다. 학습자가 미완료를 남기고 다음
챕터로 이동하기로 결정했다. 이번 정리는 전체 과제 완료나 숙달 판정이 아니다.

## 보존과 수행 범위

공식 설명·외부 사진·저장 출력을 포함한 `lesson1-local.ipynb`는 비공개
챕터 보관 영역의 `fastai-lesson1-images.ipynb`에 바이트 그대로 보존했다.
공개 저장소에는 이 회고와 학습자 설명에 근거한 개념 노트만 넣는다.
원본 수입본과 이미지 데이터는 유지한다. 모델을 재실행하거나 결과를 고치지 않았다.
셀 번호는 보관본 기준 1부터 센다.

새·숲 공식 예시를 실행하고, 공식 자유 적용 과제로 책상·모니터 분류기를
구성·실행했다. 완성된 공식 코드를 활용한 실습이며 백지 재구현으로 간주하지 않는다.
영상은 일부 시청 후 책·공식 자료 기반 한국어 해설로 전환했다.

## 과정과 저장 결과

- Kaggle에서 이미지 검색 오류가 발생해 로컬 전용 uv 환경으로 이동했다.
  환경 설정과 ddgs import 수정은 AI가 수행했다. 셀 8·10에는 ddgs 검색과
  반환 URL이 남아 있다. 근본적인 검색 서비스의 항상 동작을 보장하지 않는다.
- 새·숲: 셀 19의 파일 검증 실패 수는 0, 셀 21에는 배치 이미지가 있다.
  셀 24는 ResNet18과 fine_tune(3)의 학습 표로, 마지막 검증 손실 0.452511,
  오분류율 0.142857이다. 셀 29에는 bird 예측과 표시 확률 1.0000이 있다.
- 책상·모니터: 셀 32~34에 수집·파일 검증·배치가 있다. 셀 35의 마지막
  검증 손실은 0.029883, 오분류율은 0이다. 셀 36에는 desk 예측과 0.9953이 있다.
  그 셀의 진행 막대는 완료 모양이 아니지만 실제 예측 텍스트가 함께 남아 있다.
- 대화에서 검증 사진 수와 새 사진 수가 작으므로 모든 사진에 일반화한다고
  단정할 수 없다는 학습자의 해석을 확인했다. 당시 관찰된 검증 표본은 13개,
  별도로 예측한 책상 사진은 1장이었다.
- 사진 확장자·위치 문제를 수정한 뒤 예측했다. 학습자는 별도 사진을 넣은
  시점이 학습 후였다고 정정했다. 이를 학습 데이터 오염으로 단정하지 않는다.

## 이해와 도움의 범위

학습자는 분류 목적, 작은 검증 집합·단일 예측의 일반화 한계, 입력 해상도를
줄일 때 계산량과 세부 정보 사이의 교환 관계를 설명했다. 파라미터와
학습률·배치 크기, 자동 스케줄로 바뀌는 학습률도 구분했다.

사전학습 특징의 재사용은 설명 후 연결했지만 최적값 보장으로 확대하지 않는다.
Head, 초기 층·뒤쪽 층의 특징, loss와 metric의 구분, gradient에 따른 갱신,
세 클래스 문제에서 해당 없음이 자동으로 추가되지 않는다는 점은 해설로 보완했다.
원문 읽기와 독립적인 모델 전체 재구현은 완료로 기록하지 않는다.

## 한계와 연결

전체 검색 사진의 라벨 품질과 중복·누출 여부를 전수 검증하지 않았다.
별도 모델 체크포인트의 보존·새 커널 재현을 검증하지 않았다.
환경·파일 경로 수정은 AI 도움이고 실제 학습·예측 실행은 학습자가 했다.
