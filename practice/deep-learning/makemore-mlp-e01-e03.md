## 수행 범위와 도움

다른 컴퓨터에 남은 작업을 가져올 수 없어 학습자가 명시적으로 예외를 요청했다.
AI가 E01 기준 모델과 실행 준비 코드를 재구성했고 학습자는 이 컴퓨터에서
학습률 비교와 추가 학습을 실행했다. 다른 컴퓨터의 코드·가중치를 복구한 것은
아니며, 이 준비 코드를 학습자의 무보조 구현으로 취급하지 않는다.

E01의 dev loss 목표 달성은 저장 출력에서 확인했다. E02는 기존 보관본에 있다.
E03에서는 Bengio et al. (2003)의 본문 읽기를 학습자가 보고했고, 2절 식 (1)의
임베딩→출력 직접 연결을 문자 MLP에 적용해 실행·비교·해석했다.
논문의 단어 단위 대규모 실험을 재현한 결과는 아니다.

직접 연결과 학습·평가 함수는 학습자가 작성했으나, 구조 설명·shape 안내·
코드 검토와 오류 교정을 받았다. 이후 별도 재구현에서 제공한 준비 코드와
API 도움의 범위는 재구현 회고에 구분했다. 영상 전체 시청 여부나 공식 채점
통과를 새로 확인한 것은 아니다.

## E01: 학습률 비교와 추가 학습

문맥 3문자, 임베딩 차원 10, 은닉 유닛 200, 배치 32, 출력 문자 27개인 MLP다.
모델 seed 2147483647, 배치·이름 분할 seed 42로 CUDA에서 비교했다.
학습·검증·테스트는 이름을 먼저 나눈 뒤 문맥과 정답을 만든다(셀 3~5).

| 조건 | 누적 학습 횟수 | train loss | dev loss | 현재 근거 |
|---|---:|---:|---:|---|
| lr 0.1 | 20,000 | 2.2630279827600956 | 2.296643974322721 | 셀 2의 비교표; 이전 저장 출력에서 옮겼다는 주석 |
| lr 0.01 | 20,000 | 2.2722113385523612 | 2.2844026739406313 | 셀 2의 비교표 |
| lr 0.03 | 20,000 | 2.231744363877481 | 2.251827299092364 | 셀 7 학습 로그·평가 |
| lr 0.03 추가 학습 | 40,000 | 2.1906464375855577 | 2.216848084721916 | 셀 11 평가; 당시 lr은 대화에서 실행 로그로 확인 |
| lr 0.01로 낮춰 추가 학습 | 60,000 | 2.162177297227926 | 2.190618965184286 | 셀 10~11 |

마지막 dev loss는 E01의 2.2 미만 목표를 만족했다. 학습률을 낮추는 동시에
학습 횟수도 늘렸으므로 마지막 개선을 학습률 감소만의 효과라고 확정하지 않는다.
학습자는 이 인과 해석의 한계와 작은 학습률의 느린 갱신, 큰 학습률의
불안정 가능성을 설명했다. CPU에서 수행한 앞선 실행은 이 CUDA 비교에 섞지 않았다.

셀 7의 평가 이름은 lr 0.01로 남아 있지만 코드와 로그는 0.03이다.
셀 11의 40,000회 평가 이름에도 실제 당시 설정과 다른 문구가 남았다.
셀 1·9의 안내는 초기 재구성 시점의 내용으로, 현재 코드·출력과 일부 다르다.
현재 코드 셀을 한 번씩 위에서부터 실행하는 것만으로 이 반복 실행 이력이
그대로 재현되지는 않는다. 저장 출력은 가중치 체크포인트도 아니다.

## E03: 직접 연결 비교

추가 가중치는 30×27이며 0으로 초기화했다(셀 12). 셀 13의 모델은 기존
은닉층 경로의 logits에 연결된 임베딩의 직접 선형 점수를 더한다.
셀 14에서 초기 두 출력의 shape가 `(2, 27)`이고 최대 차이가 0임을 확인했다.
학습 대상은 셀 15에 모았고 파라미터 수는 11,897개에서 12,707개로 늘었다.

두 조건 모두 같은 초기화와 배치 난수 시퀀스로 돌아가 lr 0.03, 20,000회
학습하는 절차를 사용했다. 기준 학습은 셀 19, 직접 연결 학습은 셀 20이다.

| 모델 | train loss | dev loss |
|---|---:|---:|
| 직접 연결 없음 | 2.231744363877481 | 2.251827299092364 |
| 직접 연결 있음 | 2.2274179458618164 | 2.247469425201416 |

직접 연결 결과는 셀 21에 남아 있다. 기준 모델의 셀 18은 재실행으로 초기
손실 출력으로 바뀌었다. 이 챕터의 기준 학습 후 수치는 재실행 전에 대화에서
확인했고 셀 22에 옮겼다. 같은 값은 앞선 E01의 셀 7에도 있지만, 그것만을
근거로 새 E03 실행을 했다고 주장하는 것은 아니다.

학습자는 소폭 개선은 관찰했지만 한 번의 실험으로 일관된 이점을 확신할 수
없다고 해석했다. 한 seed의 직접 연결 추가 효과이며, 파라미터 수도 함께
늘어난 비교다. 반복 seed나 같은 파라미터 수로 맞춘 비교는 하지 않았다.
원본 평가 함수는 청크별 합산, 직접 연결 평가는 전체 평균이라 수치 집계
방식에도 미세한 차이가 있다. 초기 손실 차이는 미세했고 결과를 큰 효과로
과장하지 않았다. Test는 이번 비교에 사용하지 않았다.

## 구현 중 교정한 부분

- 정수 dtype의 새 가중치에 gradient를 켜려던 오류를 학습자가 dtype 실수로
  식별하고 수정했다. 기존 가중치의 dtype과 device를 참조하도록 정리했다.
- 처음에는 직접 경로만 반환하며 은닉층 bias를 더했다. 기존 경로 보존과
  출력 크기를 설명받은 뒤 두 경로의 logits를 더하도록 작성했다.
- 파일은 수정했지만 함수 정의 셀을 재실행하지 않아 이전 함수의 traceback이
  나타났다. 정의 셀을 다시 실행하고 비교했다.
- Python의 `max` 대신 Tensor의 전체 최댓값을 사용해 초기 출력 차이를 확인했다.
- 학습 데이터 대신 일반 이름 `X`, `Y`를 사용하던 부분을 수정했다.
  데이터 출력 반복문의 마지막 값이 test를 가리킬 수 있음을 짚었다.
- gradient 자체를 수정하던 갱신을 가중치 수정으로 바꾸고 `no_grad`로 감쌌다.
- 평가에서 한 행을 선택해 배치 차원이 사라지던 문제와 기존 `forward`를
  호출하던 문제를 교정했다. 보관본의 최종 코드는 수정 후 상태다.

## 논문 읽기의 확인 범위

[Bengio et al., A Neural Probabilistic Language Model (2003)](https://www.jmlr.org/papers/volume3/bengio03a/bengio03a.pdf)를
Conclusion까지 읽었다고 보고했다. 학습자는 은닉층·문맥 비교와 여러 조건을
동시에 바꿀 때의 원인 분리 한계를 설명했다. 결론의 문맥 길이에 따른 비용
증가와 큰 계산 부담도 짚었다.

전체 회상에서는 일반화를 가장 작은 에너지의 선택과 혼동했고 실험 근거와
한계를 재구성하지 못했다. 에너지 점수와 실제 전력 소비, 출력 후보 평가와
정답 입력, 새 단어 임베딩의 확률 가중평균, 문맥 길이와 단어별 임베딩 개수는
설명 후 이해 응답을 받았지만 독립 설명까지 확인한 것으로 확대하지 않는다.
병렬화·products of experts를 포함한 이 부분은 새 knowledge로 승격하지 않았다.
