# 이전 워크플로 자료

2026-10-23부터 Spec Kit 실행기와 통합 설정의 운영을 종료했다.
현재 작업은 전역 지침에 따라 코딩에는 Superpowers, 심층 조사에는
`ecc-deep-research`, 장문 작성에는 `ecc-article-writing`을 선택한다.
각 저장소의 도메인·학습자 소유권·검증 규칙이 우선한다.

- [기존 명세](../specs/)는 당시 요구·계획·검증의 참고 자료다.
- [기존 헌법 문서](memory/constitution.md)는 원래 비준·초안 상태 그대로 보존했다.
- `workflows/runs/`의 로컬 실행 이력과 기존 승인 기록은 보존한다.
- [퇴역 자산](retired/)에는 실행기·스킬·통합 설정과 함께 템플릿·기능 포인터를 보관한다.
- `migration-backups/`는 변경 직전 바이트·권한·해시를 보관하는 Git 제외 로컬 복구본이다.

이 자료의 과거 실행 명령과 모델·단계 승인 정책을 현재 지시로 사용하지 않는다.
`retired/`의 파일은 당시 경로를 보존한 사본이므로 내부 상대경로는 원래 위치를 기준으로 한다.
새 실행기를 설치하거나 과거 템플릿으로 현재 지침을 재생성하지 않는다.
