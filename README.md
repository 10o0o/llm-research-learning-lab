# LLM Learning Lab

**직접 만들고, 결과를 해석하고, 필요할 때 도움받는다.**
단기 목표는 AX/AI 애플리케이션 취업, 장기 목표는 LLM Research Engineer다.
이곳은 학습 허브이지 모든 프로젝트를 담는 프레임워크나 진도 관리 시스템이 아니다.

## 시작

1. [현재 위치와 다음 행동](STATE.md)을 연다.
2. 연결된 프로젝트 또는 작은 실험에서 직접 구현·실행한다.
3. 막히면 AI에게 흐름 설명·문법 도움·코드 검토를 요청한다.

`오늘 학습 시작` / `계속`은 STATE·현재 코드와 로드맵 해당 구간을 보고 저장된 다음 행동으로 돌아온다.
학습 중 의미 있는 변화와 `오늘 학습 종료`·중단에는 별도 요청 없이 확인된 STATE를 실제 저장한다.
미완료를 보존하고 파일 재독해·diff로 확인한다. 새 근거가 없으면 무변경, 실패하면 미저장임을 알린다.
로컬 저장과 커밋·원격 반영은 별개다. 매번 계획서·TIL·회고·퀴즈를 만들지 않는다.

## 필요한 자료만

- [로드맵](ROADMAP.md): 큰 방향과 단계의 목적.
- [커리큘럼](CURRICULUM.md): 단계별 주교재·실습·선수 개념·선택 심화.
- [실험과 기존 작업](practice/README.md): 작은 코드 실험, 과거 구현과 관찰.
- [AI 가이드](AGENTS.md): 도움과 진도 기록의 경계.
- [구조 정리·이전 기록 복구](docs/migration-20261024.md).

실제 서비스는 별도 저장소 하나에서 발전시켜도 된다. 개념마다 새 저장소를 만들지
않고, 이해하지 못한 완성 앱을 통째로 복사하지 않는다. 외부 프로젝트가 생기면
STATE에 그 작업 위치를 연결한다. 지금은 새 프로젝트 저장소를 만들지 않았다.

## 환경

기존 lab 실험은 Python 3.14와 `uv sync --frozen`을 사용한다. 프로젝트·공식 과제는
각자의 환경을 사용한다. 이 공개 클론에는 비공개 입력·Ollama 서버·모델이 포함되지 않는다.
공개 검사 통과는 실제 모델 추론이나 학습자의 이해를 의미하지 않는다.

별도 지식 노트 작성·정리는 학습 절차에 포함하지 않는다. 필요한 설명과 실험 결과는
해당 프로젝트 README에만 남기고, 현재 진도는 STATE에서 이어간다.

학습 사이트는 폐지했으며 종료 안내 페이지도 운영하지 않습니다. 자료와 현재 진도는 이 저장소에서 확인합니다. main 변경은 일반 검사만 실행하고 Pages를 배포하지 않습니다. 이전 사이트 원본은 [복구 안내](docs/migration-20261024.md)의 Git 이력에서 확인할 수 있습니다.

진도 저장 회귀검사는 합성 시나리오와 지침 문구의 정적 계약검사입니다. 실제 AI가 저장했음을 보장하는 실행 시험은 아니므로 실제 수업에서는 STATE 재독해와 diff 확인을 생략하지 않습니다.
