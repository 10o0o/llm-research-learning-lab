# LLM Research Engineer Learning Lab

단기 최우선은 **AX/AI 애플리케이션 취업 준비**, 장기 목표는 **LLM Research Engineer**입니다. 문의 처리 보조 서비스 하나를 작은 AI 기능→데이터/검색→도구 workflow→서비스 품질로 발전시키고, 이후 모델 학습 실험→작은 LM 하나→전문화 하나→독립 실험으로 깊이를 늘립니다. 목적·흐름·최소 선수를 먼저 배우고 대상 코드·실행·첫 해석은 직접 합니다. 고정 기간의 취업·완료를 보장하지 않습니다.

[현재 위치](./STATE.md) · [사용법](./USAGE.md) · [학습 로드맵](./ROADMAP.md) ·
[공통 지침](./AGENTS.md) · [역량 참고](./CURRICULUM.md) · [보류 자료](./DEFERRED.md)

## 가장 빠른 시작

저장소를 작업 공간으로 연 뒤 원하는 요청을 보냅니다.

| 요청 | 동작 |
|---|---|
| `오늘 학습 시작` | 승인된 현재 프로젝트/재선택 과정 안에서 연결된 활동을 이어서 진행 |
| `오늘 전체 학습 흐름 시작` / `전체 학습 흐름 시작` | 위 요청의 별칭; 같은 승인 범위에서 연결된 활동을 이어서 진행 |
| `계속` | `STATE.md`의 다음 독립 행동 재개 |
| `$study-session` | 같은 학습 절차를 명시적으로 호출 |
| `검토를 위해 잠시 멈춰` | 검토 대기; 학습 종료 절차는 아님 |
| `이번 주 회상` | 사용자가 주간 마지막 세션에서 수동 회상 요청 |
| `오늘 학습 종료` | 종료·확인된 북마크 갱신; 해당 세션의 승인된 변경 검증·커밋·푸시 |
| `$finish-chapter` / `이번 챕터 정리해줘` | 챕터 보관·회고·검증 및 허용된 로컬 커밋 |

실제 챕터 전환에서는 다음 챕터 전에 마무리가 기본으로 실행됩니다.
일반 종료나 주간 회상·AX/RE 단위 완료는 챕터 마무리·기록 생성·노트북 초기화를 실행하지 않습니다.

## 학습 방식과 권한

[study-session 스킬](./.agents/skills/study-session/SKILL.md)에 수업·피드백·회상
절차를 모았습니다. Agent는 [공통 지침](./AGENTS.md)의 연결을 통해 스킬을
직접 읽으며 [상세 정책](./.agents/references/learning-policies.md)도 필독합니다. 특정 도구의 자동 발견 기능에 의존하지 않습니다.

현재 승인된 실습의 실행 환경·커널·시작 자료·작업 공간은 Agent가 준비합니다.
제공된 스타터는 미완성 부분을 유지하고, 기존 구현 재현은 코드를 복구하며,
무보조 구현·회상은 빈 구현 공간에서 시작합니다. 준비 범위를 반복해서 묻지
않으며 상세 기준은 [준비 책임](./.agents/references/learning-policies.md#learning-setup-and-starting-materials)을 따릅니다.
Agent는 승인된 공식 자료를 확인해 한국어로 가르치며, 문제에 필요한 조건과 수치를
빠짐없이 제공합니다. 학습자의 교재 사전 읽기는 기본 요구가 아니며, 학습 대상의
구현·실행·첫 해석은 기본적으로 학습자가 맡습니다. 자체 프로젝트의 현재 명시적
수정·작성·필요 검증 위임은 범위대로 수행하며 보조 수행/주체를 구분합니다.
과거 도움은 미래 상시 대행 권한이나 독립 숙달의 증거가 아닙니다. 상세 절차는
[학습 스킬](./.agents/skills/study-session/SKILL.md)과 [공통 지침](./AGENTS.md)을 따릅니다.
주간 회상은 요청할 때 지난주 개념 두 개와 더 이전 개념 하나를 다룹니다.

한 번의 직접 활동은 목적·입출력·완료 경계를 가진 작은 기능의 작성→실행→첫 해석과
실제 코드/출력 피드백입니다. 충분한 답을 반복 시험하지 않습니다. 반복 실행은 Python
본체 하나, 분석/시각화가 필요하면 선택적 얇은 notebook을 사용합니다.

설명의 기준은 [주교재·보조 자료](./CURRICULUM.md#프로젝트-수업의-주교재와-보조-자료)의
연결된 강의 구간입니다. 전체 예제와 현재 코드의 흐름을 설명한 뒤 같은 서비스의 기능에
적용합니다. JS 경험을 활용해 필요한 Python 표현을 묶어 배우며, 보조 작업만으로 진도를
나누지 않습니다. 막힘별 도움과 반복 수정의 종료 기준은
[기능 수업 판단](./.agents/references/learning-policies.md#feature-lesson-decisions)에 둡니다.

[실습 선택](./ROADMAP.md#반복-실행과-관찰)과
[초기 개발 공간·서비스 지속 발전](./ROADMAP.md#초기-개발-공간과-서비스의-지속-발전)을
따릅니다. repo 시작에 작동 기능/평가 baseline 완성을 요구하지 않으며, 실제 작동·평가/
실패·직접 기여·재현 근거가 포트폴리오 주장을 제한합니다. 문서 검토/승인은 학습 재개가 아닙니다.

승인 범위·단위별 맥락/완료 기준은 [ROADMAP.md](./ROADMAP.md)에 있습니다. 공식 과제를
보충 예제나 완성 노트북 실행으로 대체하지 않습니다. 공식 과제 답안과
저작권 자료는 별도 비공개 공간에 두며, 과정별 도움 제한은 공통 지침을 따릅니다.

현재 범위와 다음 행동은 `STATE.md`에서 확인합니다. 기존 P0~P5·전체 수학/과제·고정 시간/대회 의무를 새 프로젝트의 시작 조건으로 복원하지 않습니다. [과거 북마크 인용](./practice/reviews/curriculum-transition.md)은 도움·미완료 보존용이며 현재 지시가 아닙니다. 첫 작은 기능과 **문제·직접 기능·평가/실패·재현 조건·기여/도움·주장 한계**를 갖추면 조기 JD 비교 자료로 활용할 수 있고, 주 포트폴리오는 AX-01~04 한 서비스입니다. 실제 필수/우대·연차/학위·운영 요구는 읽은 원문과 따로 대조합니다.
`STATE.md`는 두 AI 도구가 공유하는 하나의 재개 북마크입니다. 확인된 위치가
바뀌면 사전 승인 없이 수정하되 그 자체로 커밋·푸시를 허용하지 않습니다.
명시적 학습 종료는 해당 세션의 검증된 변경만 커밋·푸시하는 기존 권한입니다. TIL·knowledge의 단독 작성은 명시적으로
요청합니다. 챕터 마무리의 보관·knowledge·초기화·로컬 커밋 권한은
[finish-chapter](./.agents/skills/finish-chapter/SKILL.md)에 한정되며, 푸시는 포함하지 않습니다.

## 지식 서재 웹

`knowledge/`를 홈·검색·분야별 목록·상세 화면으로 읽는
[GitHub Pages 사이트](https://10o0o.github.io/llm-research-learning-lab/)입니다.
일반 학습 중에는 사이트를 변경하지 않습니다.

Node와 npm을 준비한 뒤 `web/`에서 `npm ci`, `npm run build`, `npm run preview`를
실행합니다. [웹 실행·검증 안내](./web/README.md)를 참고하세요. `main`에 push하면
`public-validation` 검증 후 배포합니다. 수동 재배포는 Actions의 해당 workflow에서
`main`을 선택하고 **Run workflow**를 실행합니다. 다른 branch와 PR은 검증만 합니다.
실패하면 해당 job 로그를 확인합니다. 이 안내는 자동 push 권한이 아닙니다.
