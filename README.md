# AI Learning Hub

단기에는 **AX / AI 애플리케이션 엔지니어**, 장기에는 **LLM Research Engineer**를 목표로 공부한다.
이 저장소에서 따라갈 자료와 현재 위치를 확인하고, 직접 구현·실행하는 일은 **학습자 소유의 외부 실습 저장소**에서 진행한다.

## 지금 시작하기

1. [현재 위치와 다음 행동](STATE.md)을 확인한다.
2. 선택한 [공식 강의·자료](CURRICULUM.md)의 해당 구간을 연다.
3. 연결된 외부 실습 저장소에서 직접 수행하고 필요한 설명·리뷰를 받는다.
4. 실제로 한 일과 남은 문제를 바탕으로 STATE를 갱신한다.

`오늘 학습 시작` / `계속`은 저장된 위치부터 안내한다. 아직 자료가 선택되지 않았다면
추천 자료 하나를 제시하고 선택을 확인한다. 추천을 수강 기록으로 바꾸거나 자체 과제를 먼저 시작하지 않는다.

주자료는 AX의 **LLM Zoomcamp**, 모델 기반의 **Karpathy**를 추천한다.
실제로 선택한 과정은 STATE 한 곳에서 관리한다. 강의 하나의 공식 순서와 과제를 기본으로
따라가고, 보충 자료는 현재 막힌 부분에 필요할 때 연다.

## 실제 작업은 어디에서 하나

- 강사·저자의 저장소: 강의, starter, 테스트와 참고 구현의 출처.
- 나의 실습 저장소: 직접 작성한 코드, 실행 결과와 필요한 짧은 설명.
- 이 허브: 그 두 공간의 링크와 이어갈 위치.

강의나 지속 프로젝트 단위로 실습 공간을 둔다. 개념마다 저장소를 만들거나
완성 코드를 통째로 먼저 복사하지 않는다. 연결 방법은 [외부 실습 안내](docs/external-practice.md)를 따른다.
공식 과제의 AI·답안 공개 정책은 해당 과제를 선택할 때 확인한다.

허브를 이용하기 위한 Python 환경 설치는 필요 없다. 각 실습은 해당 과정·프로젝트의 환경을 사용한다.
일일 TIL, 점수판, 종료 퀴즈, 별도 진도 데이터베이스를 요구하지 않는다.

2026-10-26 이전 실습과 환경은 [전환 직전 보관본](archive/README.md)에 있다.
GitHub 주소는 기존 연결을 유지하기 위해 그대로 사용하며, 학습 사이트나 Pages는 운영하지 않는다.
